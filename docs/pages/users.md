## 1. التحليل التشغيلي والمعماري (Operational & Architectural Analysis)

### 🎯 الغرض من الصفحة:
تُمثل شاشة **إدارة حسابات المستخدمين والموظفين (Users & Staff Management)** مركز إدارة الهوية والوصول للمؤسسة:
1. **إدارة حسابات الموظفين:** إنشاء، تعديل، إيقاف/تفعيل، وحذف مستخدمي المنظومة (كاشير، أمناء مخازن، محاسبين، ومديرين).
2. **ربط الأدوار والصلاحيات:** تعيين الدور الوظيفي (Role) وربطه بالصلاحيات الدقيقة مع إمكانية الانتقال المباشر لمصفوفة الصلاحيات (`/roles`).
3. **تخصيص الفروع والمخازن الافتراضية:** ربط كل موظف بالفرع أو نقطة البيع الافتراضية الخاصة به.
4. **البحث والفلترة الفورية:** البحث بالاسم ورقم الهاتف والبريد الإلكتروني وتصفية حسب الدور الوظيفي مع الترقيم التلقائي Pagination.
5. **التحكم الفوري بحالة النشاط (Toggle Active):** تفعيل أو تعطيل دخول الموظف فورياً بنقرة واحدة دون الحاجة لحذف حسابه.
6. **نافذة مودال موحدة للإضافة والتعديل (`UserFormModal.vue`):** باستخدام `AppModal.vue` وعناصر `BaseInput`, `BaseSelect`, `BaseCheckbox`.

## 2. هيكلية وشجرة المكونات (Component Tree & Architecture)

تم تفكيك الصفحة من ملف بـ 471 سطرًا إلى **Thin Orchestrator** ومكونات أحادية المسؤولية:

```text
resources/js/
├── views/Users/
│   └── UsersView.vue                          <-- Thin Orchestrator (~75 lines)
├── Components/Users/
│   ├── UsersFilterBar.vue                     <-- شريط البحث بالاسم/الهاتف وفلتر الأدوار
│   ├── UsersTable.vue                         <-- جدول المستخدمين + بطاقات الهواتف اللمسية المتراصة والترقيم
│   └── UserFormModal.vue                      <-- نافذة إضافة وتعديل بيانات المستخدم وكلمة المرور والفرع
└── Composables/
    └── useUsers.js                            <-- كبسولة المنطق والاتصال بالـ API وإدارة الحسابات
```

## 3. عناصر النماذج والواجهات المشتركة المستخدمة

* `PageHeader.vue`: ترويسة الصفحة، زر الانتقال لمصفوفة الصلاحيات، وزر إضافة موظف جديد.
* `BaseButton.vue`: أزرار الحفظ والإجراءات مع مؤشرات التحميل.
* `BaseSearchInput.vue`: حقل البحث الفوري.
* `BaseInput.vue`: حقول إدخال الاسم ورقم الهاتف والبريد وكلمة المرور.
* `TableSkeleton.vue`: هيكل التحميل الوميضي للجداول.
* `EmptyState.vue`: حالة عدم وجود مستخدمين مطابقين للبحث.
* `AppModal.vue`: الحاوية الموحدة لنافذة المستخدم.

## 4. الاعتماديات والـ APIs المرتبطة

| العملية | الـ Endpoint | الطلب (Request Payload) | الاستجابة |
| :--- | :--- | :--- | :--- |
| **جلب قائمة المستخدمين** | `GET /api/v1/users` | `search`, `role`, `page` | قائمة المستخدمين + الأدوار + الفروع + الترقيم |
| **إنشاء مستخدم جديد** | `POST /api/v1/users` | `name`, `phone`, `email`, `password`, `role`, `default_store_id`, `is_active` | إنشاء الحساب وتعيين الصلاحيات |
| **تعديل بيانات مستخدم** | `PUT /api/v1/users/{id}` | `name`, `phone`, `email`, `password?`, `role`, `default_store_id`, `is_active` | تحديث البيانات |
| **تبديل حالة النشاط** | `PATCH /api/v1/users/{id}/toggle-active` | - | تبديل حالة الحساب (نشط / معطل) |
| **حذف مستخدم** | `DELETE /api/v1/users/{id}` | - | الحذف الآمن للمستخدم |
