# 🔄 وثيقة المكون والصفحة: سجل المرتجعات وإشعارات الخصم والإرجاع (`ReturnsView`)

## 1. النظرة العامة والتحليل التشغيلي:
* **اسم الصفحة:** سجل المرتجعات وإشعارات الخصم (Returns Log)
* **المسار (Route):** `/returns`
* **اسم المسار (Route Name):** `returns.index`
* **الصلاحية المطلوبة (Permission):** `returns.manage`
* **الملف الرئيسي:** `resources/js/views/Returns/ReturnsView.vue` (~80 سطرًا).
* **الغرض والتحليل التشغيلي:**
  * السجل المركزي لإدارة وتوثيق كافة مرتجعات المبيعات (من العملاء) ومرتجعات المشتريات (إلى الموردين).
  * تتبع إشعارات الخصم والإضافة وإعادة البضائع للمخزن أو استرداد قيمتها نقداً أو قيداً على الحساب.
  * مؤشرات KPI فورية تلخص إجمالي قيمة المرتجعات، عدد العمليات، ونسبتها مقارنة بالمبيعات والمشتريات.
  * فلترة متقدمة حسب نوع المرتجع (مبيعات / مشتريات)، الفرع، التاريخ، ورقم المستند الأصلي.
  * معاينة سريعة لبنود المرتجع وسبب الإرجاع وتفاصيل استرداد النقدية.

---

## 2. هيكلية وشجرة المكونات (Component Tree):
```text
ReturnsView.vue (~80 lines)
├── ReturnsHeader.vue                 <-- رأس الصفحة مع زر إنشاء مرتجع جديد وتصدير البيانات
├── ReturnsMetricsGrid.vue            <-- بطاقات المؤشرات: إجمالي المرتجعات، مرتجعات المبيعات، مرتجعات المشتريات
├── ReturnsFilterBar.vue              <-- شريط الفلاتر: البحث، النوع (مبيعات/مشتريات)، النطاق الزمني، والفرع
├── ReturnsTable.vue                  <-- جدول المرتجعات مع أرقام الفواتير الأصلية وطريقة التسوية
└── ReturnDetailsModal.vue            <-- نافذة معاينة تفاصيل المرتجع، البنود المعادة، وسبب الرد
```

## 3. العناصر المشتركة ومخازن الحالة:
* **المكونات المشتركة:** `PageHeader.vue`, `BaseButton.vue`, `DataTable.vue`, `AppModal.vue`.
* **المخازن المستخدمة:** `useAuthStore`, `useAppConfigStore`.
* **الـ Composables:** `useFormatters.js` لتنسيق المبالغ المالية (`formatMoney`) وتنسيق الكميات.

---

## 4. الاعتماديات والـ APIs:
* `GET /api/v1/returns`: استعراض قائمة المرتجعات مع الفلاتر وترقيم الصفحات:
  * **الكنترولر:** `App\Http\Controllers\Api\ReturnController@index`
  * **Resource:** `App\Http\Resources\ReturnResource`
* `GET /api/v1/returns/{id}`: جلب تفاصيل مستند المرتجع وبنوده:
  * **Resource:** `App\Http\Resources\ReturnResource`
* `DELETE /api/v1/returns/{id}`: إلغاء مستند المرتجع (للمدير فقط).

---

## 5. نطاق الفروع وعزل البيانات (Store Scoping):
* ترسل الصفحة ترويسة `X-Store-Id` لتحديد الفرع والمخزن المعني بالمرتجع.
* يتم التدقيق الصارم عبر `ClientStoreGuard::verified($request)`.
* أي محاولة للوصول لمرتجعات فرع غير مصرح به تُقابل بالرفض برمز **HTTP 403** مع كود `store_access_denied`.

---

## 6. القواعد المالية الصارمة والمخزون:
1. **عكس المخزون الآلي (`Stock Reversal`):** في مرتجع المبيعات، تُعاد الكميات فوراً لرصيد مخزن الفرع؛ وفي مرتجع المشتريات تُخصم من رصيد المخزن داخل `DB::transaction()` وباستخدام `lockForUpdate()`.
2. **تسوية الحسابات النقدية والآجلة:** يُعدل رصيد العميل أو المورد آلياً، أو يُخصم المبلغ من الخزينة اليومية عبر مكتبة `bcmath`.
3. **الدقة المالية `DECIMAL(12,3)`:** كافة المبالغ تُحسب بدقة 3 خانات عشرية مع تطبيق التقريب المتماثل للنصف للأعلى (`half-up rounding at 3 dp`).
