# 📑 وثيقة المكون والصفحة: كشف حساب وأستاذ العميل (`CustomerStatementView`)

## 1. النظرة العامة والتحليل التشغيلي:
* **اسم الصفحة:** كشف حساب وأستاذ العميل (Customer Account Statement)
* **المسار (Route):** `/customers/:id/statement`
* **اسم المسار (Route Name):** `customers.statement`
* **الصلاحية المطلوبة (Permission):** `customers.manage` (أو `customers.statement`)
* **الملف الرئيسي:** `resources/js/views/Customers/CustomerStatementView.vue` (~54 سطرًا).
* **الغرض والتحليل التشغيلي:**
  * كشف الحساب والأستاذ المساعد التفصيلي المعتمد لمطابقة وتدقيق معاملات العميل.
  * استعراض الرصيد الافتتاحي ما قبل الفترة، إجمالي المبيعات الآجلة (مدين)، إجمالي السدادات والمقبوضات (دائن)، والمرتجعات، وصولاً إلى الرصيد النهائي المستحق.
  * فلترة متقدمة حسب النطاق الزمني لتوليد كشوف حساب شهرية، ربع سنوية، أو سنوية.
  * جدول زمني تسلسلي يوضح تاريخ كل معاملة، رقم المستند، البيان، المبالغ المدينة، المبالغ الدائنة، والرصيد التراكمي المتحرك.
  * دعم كامل للطباعة الرسمية الفورية A4 المنسقة مع الترويسة، والتصدير لـ PDF، والمشاركة الفورية عبر واتساب.

## 2. هيكلية وشجرة المكونات (Component Tree):
```text
CustomerStatementView.vue (~54 lines)
├── CustomerStatementHeader.vue      <-- بيانات العميل الأساسية، الهاتف، الحد الائتماني، وأزرار الطباعة والمشاركة
├── CustomerStatementSummaryCards.vue<-- بطاقات التلخيص المالي: الرصيد السابق، المبيعات، المدفوعات، الرصيد المستحق
├── CustomerStatementFilterBar.vue   <-- شريط فلترة الفترة الزمنية ونوع المعاملات
└── CustomerStatementTable.vue       <-- جدول حركة الأستاذ: التاريخ، المستند، البيان، مدين، دائن، والرصيد التراكمي
```

## 3. العناصر المشتركة ومخازن الحالة:
* **المكونات المشتركة:** `PageHeader.vue`, `BaseButton.vue`, `DataTable.vue`.
* **المخازن المستخدمة:** `useAuthStore`, `useAppConfigStore`.
* **الـ Composables:** `useFormatters.js` لتنسيق المبالغ المالية بدقة (`formatMoney`) والتواريخ.

## 4. الاعتماديات والـ APIs:
* `GET /api/v1/customers/{id}/statement`: جلب كشف الحساب والمعاملات التفصيلية للعميل:
  * **الكنترولر:** `App\Http\Controllers\Api\CustomerController@statement`
  * **الصلاحية المطلوبة:** `customers.statement` أو `customers.manage`

---

## 5. نطاق الفروع وعزل البيانات (Store Scoping):
* يتم التحقق الأمني من أحقية المستخدم في استعراض بيانات العميل وحساباته التابعة لمؤسسة المستأجر.
* في حال طلب معاملات فرع محدد، يتم التحقق عبر `ClientStoreGuard::verified($request)`؛ ومحاولة الوصول غير المصرح بها تنتج خطأ **HTTP 403** بكود `store_access_denied`.

---

## 6. القواعد المحاسبية الصارمة والدقة المالية:
1. **معادلة الرصيد التراكمي المستمر:**
   $$\text{Running Balance}_i = \text{Running Balance}_{i-1} + \text{Debit}_i - \text{Credit}_i$$
2. **الدقة المالية `DECIMAL(12,3)` و `bcmath`:** كافة بنود الحساب والرصيد التراكمي تُعالج بالكامل عبر دوال `bcmath` بـ 3 خانات عشرية لمنع أي تفاوت أو فروق طفيفة في الدفاتر المحاسبية.
