## 1. التحليل التشغيلي والمعماري (Operational & Architectural Analysis)

### 🎯 الغرض من الصفحة:
تُمثل شاشة **مصفوفة الأدوار والصلاحيات (Roles & Permissions Matrix)** مركز الأمان والتحكم بصلاحيات المنظومة:
1. **التحكم بالصلاحيات الدقيقة للمستخدمين:** تحديد الصلاحيات التشغيلية لكل دور (كاشير، أمين مخزن، محاسب، إلخ) على مستوى كل موديول (فواتير، مبيعات، مخزون، مشتريات، عملاء، موردين، خزينة، تقارير، إعدادات).
2. **حماية صلاحيات السوبر أدمن (Admin Role Protection):** تنبيه وقفل مدمج لحساب المدير العام لضمان عدم سحب الصلاحيات الإدارية الحساسة بالخطأ.
3. **تحديد الكل / إلغاء تحديد الكل السريع:** إمكانية تفعيل أو تعطيل كامل صلاحيات الموديول بنقرة واحدة (`select_all` / `deselect_all`).
4. **حفظ فوري للصلاحيات وتحديث العداد:** حفظ الصلاحيات المحدثة وإشعار المستخدم فورياً عبر SweetAlert وتحديث العداد الحي للصلاحيات المفعلة.

## 2. هيكلية وشجرة المكونات (Component Tree & Architecture)

تم تفكيك الصفحة من ملف بـ 213 سطرًا إلى **Thin Orchestrator** ومكونات أحادية المسؤولية:

```text
resources/js/
├── views/Roles/
│   └── RolesView.vue                          <-- Thin Orchestrator (~65 lines)
├── Components/Roles/
│   ├── RolesSelectorGrid.vue                  <-- شبكة بطاقات اختيار الأدوار وعداد الصلاحيات
│   ├── RoleAdminNotice.vue                    <-- تنبيه حماية صلاحيات مدير النظام
│   └── PermissionModulesGrid.vue              <-- شبكة موديولات الصلاحيات وتحديد الكل
└── Composables/
    └── useRoles.js                            <-- كبسولة المنطق والاتصال بالـ API وحفظ الصلاحيات
```
