# قاموس المصطلحات

الكلمات اللي بتتكرر في الدليل وفي شاشات النظام، بمعناها في «إبراء».

| المصطلح | معناه في إبراء |
|---|---|
| **المؤسسة / المحل** | الحساب الواحد على إبراء. ليها قاعدة بيانات منفصلة، وعنوان دخول خاص بيها (مثلًا `mahal.ibraa.app`). |
| **الفرع** | مكان بيع ليه مخزون ودرج كاش، وبيتبعله مستخدمين. |
| **المخزن** | مكان تخزين بضاعة من غير بيع مباشر غالبًا. بيتحسب ضمن حدود الباقة. |
| **عربية التوزيع** | فرع متنقّل بمخزون خاص بيه، لتجار الجملة اللي بيلفّوا على المحلات. |
| **الكاشير (POS)** | شاشة البيع السريع: بحث أو باركود، سلة، دفع، طباعة. |
| **الوردية** | فترة شغل كاشير على درج: بتتفتح برصيد افتتاحي وبتتقفل بعدّ الفلوس ومقارنتها بالمتوقع. |
| **الرصيد الافتتاحي (العهدة)** | الفلوس اللي في الدرج أول الوردية علشان الفكة. |
| **عجز / زيادة الوردية** | الفرق بين الفلوس المعدودة عند التقفيل والمبلغ اللي النظام متوقعه. |
| **تقرير التقفيل** | ملخص الوردية: المبيعات بكل طريقة دفع، المرتجعات، المصروفات، والمتوقع في الدرج. |
| **فاتورة بيع** | عملية بيع محفوظة: أصناف، خصم، عميل، طريقة دفع. بتخصم من المخزون وبتسجّل في الخزنة. |
| **الزبون النقدي (العميل العام)** | عميل افتراضي للبيع الكاش من غير اسم. مش بيتحسب في حد العملاء. |
| **الآجل** | البيع أو الشراء على الحساب: الفلوس بتتسجّل دين على العميل أو للمورد. |
| **دفع جزئي** | جزء من الفاتورة يتدفع دلوقتي والباقي يبقى آجل. |
| **سند قبض** | إيصال تحصيل فلوس من عميل (أو أي مصدر داخل للخزنة). |
| **سند صرف** | إيصال دفع فلوس لمورد (أو أي مصروف خارج من الخزنة). |
| **كشف الحساب** | كل حركات عميل أو مورد بالتاريخ مع الرصيد بعد كل حركة. |
| **المرتجع** | رجوع صنف أو أكتر من فاتورة بيع: البضاعة بترجع المخزن، والفلوس بترجع كاش أو بتتخصم من مديونية العميل. |
| **الخزنة (الخزينة)** | أرصدة الفلوس لكل فرع حسب طريقة الدفع (كاش، إنستاباي، محفظة…). |
| **اليومية** | شاشة بتعرض حركة الدرج والورديات وكل الفلوس الداخلة والخارجة في اليوم. |
| **المصروف** | فلوس خارجة لتشغيل المحل (إيجار، كهربا، نقل…) مش لشراء بضاعة. |
| **فاتورة مشتريات** | بضاعة داخلة من مورد: بتزوّد المخزون وبتحدّث تكلفة الصنف. |
| **تكلفة الصنف** | اللي الصنف كلّفنا. بتتحسب كمتوسط مرجّح بعد كل شراء (التفاصيل في فصل المخزون). |
| **حركة المخزون (كارت الصنف)** | سجل كل دخول وخروج لصنف: بيع، مرتجع، شراء، تحويل، تسوية، استيراد. |
| **التحويل المخزني** | نقل بضاعة من فرع أو مخزن لمكان تاني. |
| **التسوية** | تعديل يدوي للرصيد بسبب عجز أو هالك أو زيادة. |
| **الخلطة (المزج)** | بيع خلطة من كذا صنف بنسب (زي خلطات البن) في فاتورة واحدة. |
| **إعادة الطلب الذكي** | اقتراح كميات للشراء حسب سرعة البيع والرصيد الحالي. |
| **الصلاحية** | إذن بعمل حاجة معينة (مثلًا حذف، رؤية التكلفة، فتح التقارير). |
| **الدور** | مجموعة صلاحيات جاهزة (مدير، كاشير…) بتتدّي للمستخدم. |
| **الباقة** | خطة الاشتراك: بتحدد الحدود (عدد الفواتير، الأصناف، المستخدمين…) والمزايا المتاحة. |
| **الباقة المجانية الدايمة** | باقة بصفر جنيه ملهاش تاريخ انتهاء، بحدود على حجم الشغل. |
| **الحد** | أقصى عدد مسموح في الباقة لبند معيّن. عند 80% بيظهر تنبيه، وعند 100% بيتمنع إضافة الجديد بس. |
| **السماحية** | بنود الباقة الهيكلية (الفروع، المخازن، العربيات): استخدامها بالكامل طبيعي ومش بيطلع تحذير. |
| **الإضافة (Add-on)** | زيادة بتتشترى فوق الباقة (مستخدم أو مخزن أو عربية إضافية). |
| **استثناء المحل** | حد أو ميزة مختلفة لمحل معيّن عن باقته، بيحددها فريق إبراء بسبب وتاريخ انتهاء اختياري. |
| **فترة التجربة** | أيام مجانية على باقة مدفوعة. لو المسجّل ذاتيًا ما دفعش في الآخر بينزل للباقة المجانية. |
| **حالة الاشتراك** | تجربة، نشط، متأخر في الدفع، قراءة فقط، موقوف، ملغي، مؤرشف (التفاصيل في الفصل 8). |
| **قراءة فقط** | المحل يقدر يشوف بياناته ويطبعها بس، من غير إضافة أو بيع جديد. |
| **الأرشفة** | قفل المحل مع الاحتفاظ بكل بياناته. ممكن يرجع بطلب للدعم. مفيش مسح تلقائي. |
| **المحل الخامل** | محل مجاني ما اتفتحش 60 يوم أو أكتر (تذكير)، و90 يوم (أرشفة). |
| **التسجيل الذاتي** | العميل بيعمل حسابه بنفسه من الموقع ويأكّد إيميله بكود من 6 أرقام. |
| **لوحة إدارة المنصة (الكونسول)** | الشاشات الخاصة بفريق إبراء لإدارة المحلات والباقات والفواتير والتحديثات. |
| **التحقق بخطوتين** | كود إضافي من تطبيق على الموبايل لفريق إبراء قبل العمليات الحساسة. |
| **سجل النشاط / سجل المراجعة** | تسجيل مين عمل إيه وإمتى، جوه المحل (سجل النشاط) ولفريق إبراء (سجل المراجعة). |
| **سلة المحذوفات** | المكان اللي بيروح له المحذوف (أصناف، عملاء…) علشان يترجع لو اتحذف بالغلط. |
