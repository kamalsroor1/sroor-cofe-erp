# كتالوج المزايا

«إبراء» فيه المزايا دي كلها النهارده. الملف ده قايمة واحدة للمبيعات والدعم والإدارة عشان تشوف كل حاجة في مكان واحد، ومعاها الباقة اللي بتشملها. كل ميزة اتراجعت على الكود الحالي، واللي مش مكتمل متعلّم «جزئي».

**دليل الأعمدة** (أسماء الباقات زي ما هي في السيستم):

| الرمز | المعنى |
|---|---|
| التجربة | الباقة المجانية الدايمة (مش تجربة لفترة محدودة) |
| البداية / النمو / الأعمال | الباقات المدفوعة (499 / 999 / 1,499 جنيه شهريًا قبل الضريبة) |
| ✓ | الميزة مشمولة في الباقة |
| — | غير مشمولة |
| إضافة | مش في الباقة لكن تتشترى كإضافة مدفوعة (الإضافات متاحة للباقات المدفوعة بس) |
| رقم | حد معين في الباقة (التفاصيل في آخر الملف) |

الميزات اللي ليها `✓` في كل الأعمدة معناها إنها أساسية في كل باقة. الأرقام بتتغيّر لكل محل لو الفريق ضبط «استثناء» للمحل (موجود في قسم لوحة المنصة).
