# 🧾 موديول إدارة المبيعات والفواتير (Sales & Invoicing Module)

## 1. نبذة عن الموديول:
موديول المبيعات هو السجل المحاسبي المركزي لكافة العمليات المالية الصادرة، يوثق كافة الفواتير النقدية والآجلة، وينظم حسابات العملاء، ويضمن الامتثال الضريبي الكامل.

---

## 2. صفحات وشاشات الموديول:
* **[سجل فواتير المبيعات (Invoices)](../pages/invoices.md):** استعراض وأرشفة وطباعة وإلغاء فواتير المبيعات.

---

## 3. مخطط تدفق دورة المبيعات والفواتير:
```text
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│  إصدار الفاتورة  │ ────> │  اعتماد السداد   │ ────> │  طباعة وتصدير    │
│  (POS أو مبيعات) │       │ (نقدي أو آجل)   │       │ (A4 أو 80mm)    │
└─────────────────┘       └─────────────────┘       └─────────────────┘
                                                             │
                                                             ▼ (في حال الإلغاء)
                                                    ┌─────────────────┐
                                                    │  إلغاء الفاتورة   │
                                                    │  وعكس المخزون    │
                                                    └─────────────────┘
```

---

## 4. القواعد المحاسبية الصارمة:
1. **عدم الحذف الفيزيائي للفواتير:** الفواتير الملغاة تظل مسجلة برقمها المتسلسل مع تمييز حالتها بعلامة "ملغاة" للحفاظ على تسلسل الدفاتر الضريبية.
2. **عكس حركة المخزون آلياً:** عند إلغاء أي فاتورة، تُعاد الكميات المباعة فوراً إلى رصيد المخزن المسجل بالفرع داخل نفس الـ Transaction.
3. **تحديث حسابات العملاء:** إذا كانت الفاتورة آجلة، يتم خصم قيمتها من رصيد مديونية العميل فور الإلغاء.
