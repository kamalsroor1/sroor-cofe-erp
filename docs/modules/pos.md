# ☕ موديول نقطة البيع والورديات والكاشير (Point of Sale Module)

## 1. نبذة عن الموديول:
موديول نقاط البيع هو المحرك التشغيلي الأسرع في نظام "سرور كوفي ERP"، مصمم لتحقيق أعلى كفاءة في خدمة العملاء، وتسجيل الطلبات في ثوانٍ معدودة، مع التحكم الكامل في النقدية وحركات الخزينة والورديات.

---

## 2. صفحات وشاشات الموديول:
* **[نقطة البيع السريعة (POS)](../pages/pos.md):** شاشة الكاشير التفاعلية وإصدار الفواتير اللحظية.

---

## 3. مخطط تدفق دورة البيع والكاشير (POS Workflow):
```text
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│  افتتاح الوردية  │ ────> │  إضافة الأصناف   │ ────> │  تطبيق الخصم     │
│ (الرصيد الافتتاحي)│       │ (الباركود/اللمس) │       │ (بند / فاتورة)   │
└─────────────────┘       └─────────────────┘       └─────────────────┘
                                                             │
                                                             ▼
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│  قفل الوردية     │ <──── │  طباعة الإيصال   │ <──── │  اختيار طريقة   │
│  (جرد الخزينة)   │       │  (حراري 80mm)   │       │  الدفع والسداد  │
└─────────────────┘       └─────────────────┘       └─────────────────┘
```

---

## 4. القواعد المعمارية والمالية الصارمة للموديول:
1. **القفل السطري للمخزون (`lockForUpdate()`):** منع البيع المزدوج للأصناف أو حدوث عجز مخزني عند تعدد الكاشيرات.
2. **العمليات داخل `DB::transaction()`:** تسجيل الفاتورة، خصم المخزون، وتحديث رصيد الخزينة يتم كوحدة واحدة لا تتجزأ.
3. **الدقة المالية `DECIMAL(12,3)` ودوال `bcmath`:** حساب الضرائب والخصومات بدقة متناهية بدون أي تقريب عشوائي.
4. **دعم العمل دون اتصال بالإنترنت والمزامنة اللحظية.**
