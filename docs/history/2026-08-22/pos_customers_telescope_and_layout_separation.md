# سجل تعديل: نافذة عملاء الـ POS، تأمين Telescope، وفصل قوالب السوبر أدمن

* **التاريخ والوقت:** 2026-08-22 21:45
* **الدور المفعل:** Fullstack Architect (Backend Architect & Frontend UI)
* **الهدف:** حل مشكلة استعلام إصدارات التطبيق عبر الـ API، تفعيل البحث السريع عن العملاء وإضافتهم في الـ POS، فصل قالب السوبر أدمن كلياً عن قالب المستأجر، وتأمين وصول Laravel Telescope حصرياً للسوبر أدمن.

## 1. الملفات المعدلة:
* `[MODIFIED]` App.vue - فصل القوالب جذرياً: عرض SuperAdminLayout لشاشات /super-admin/* وإلغاء تحميل SpaLayout التشغيلي.
* `[MODIFIED]` PosView.vue - بناء نافذة اختيار العميل التفاعلية وإضافته السريعة مع البحث الفوري ودعم شريحتي الأسعار (تجزئة / جملة).
* `[MODIFIED]` SuperAdminLayout.vue - إضافة رابط مراقب النظام Telescope مع الـ Token Bridge.
* `[MODIFIED]` AppUpdateController.php - تصحيح أخطاء الـ Null Safety لمصفوفة latest_version.
* `[MODIFIED]` AppVersion.php - إضافة getConnectionName() لربط الاستعلامات دائماً بقاعدة البيانات المركزية.
* `[MODIFIED]` TelescopeServiceProvider.php - تأمين صلاحية viewTelescope للسوبر أدمن فقط مع دعم فك التوكن.
* `[MODIFIED]` web.php - إضافة مسار الجسر /telescope-access لبدء جلسة الويب المركزية تلقائياً.
* `[MODIFIED]` AGENTS.md - تحديث دليل التشغيل بالقواعد والمعايير المعمارية الحديثة للـ SPA والفصل التام للقوالب.

## 2. القرارات التقنية:
1. **فصل القوالب (Layout Isolation):** منع تداخل شاشات السوبر أدمن المركزية مع شاشات المستأجرين عبر التحقق من المسار في App.vue.
2. **اتصال الموديلات المركزية:** توجيه استعلامات AppVersion لقاعدة البيانات المركزية لمنع أخطاء الجداول المفقودة في المستأجرين.
3. **أمان Telescope:** تأمين تليسكوب بالكامل للسوبر أدمن فقط وربطه بجسر مصادقة مبني على Sanctum tokens.
