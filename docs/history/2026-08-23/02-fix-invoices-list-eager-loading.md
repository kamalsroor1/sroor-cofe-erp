# سجل تعديل: حل مشكلة عدم ظهور الفواتير في صفحة المبيعات (Unknown column code)
* **التاريخ والوقت:** 2026-08-23 01:35
* **الدور المفعل:** Backend Architect & QA Testing
* **الهدف:** فحص واكتشاف سبب عدم رجوع الفواتير في صفحة المبيعات على السيرفر بعد إنشائها في الـ POS وحلها نهائياً.

## 1. المشكلة المكتشفة على السيرفر:
* عند استدعاء `GET /api/v1/invoices`، كان الاستعلام يطلب حقول غير موجودة في جدول العملاء `customers`:
  `with(['customer:id,name,phone,code,balance'])`
  مما كان يتسبب في خطأ SQL 500:
  `SQLSTATE[42S22]: Column not found: 1054 Unknown column 'code' in 'SELECT'`
* الفرونت إند في `InvoicesView.vue` كان يلتقط الخطأ ويعرض مصفوفة فارغة `0 فواتير`.

## 2. التعديلات المنفذة:
* `[MODIFIED]` `backend/app/Http/Controllers/Api/InvoiceController.php`:
  - تصحيح Eager Loading للعميل إلى `customer:id,name,phone,current_balance`.
  - معالجة `$rawStoreId` بمرونة تامة للتأكد من أنه رقمي وموجب قبل التصفية بالفرع، ودعم تصفية `all`.
* اختبار الـ API مباشرة على سيرفر الإنتاج لجميع الحالات (`no store`, `store_id=1`, `store_id=all`) والتأكد من إرجاع الفواتير بنجاح 100%.
