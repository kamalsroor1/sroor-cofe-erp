# سجل تعديل: حل مشكلة تحميل الـ PDF وتحسين تجربة الموبايل وإضافة شارة جديد في السايدبار

* **التاريخ والوقت:** 2026-09-04 03:40
* **الدور المفعل:** Frontend & Mobile UI Specialist / Full-stack Developer
* **الهدف من التعديل:** 
  1. حل مشكلة حظر أو تشوه ملف الـ PDF عند التنزيل (حيث كانت بعض المتصفحات على الهاتف أو سطح المكتب تحظر التنزيل أو تحفظ الملف بصيغة غير معروفة بسبب الحروف العربية في الـ download attribute).
  2. تحسين شامل لواجهات عروض الأسعار على شاشات الهاتف المحمول (نظام التبويبات + الشريط العائم السفلي + بطاقات الموبايل).
  3. إضافة شارة تمييزية تفاعلية `جديد ✨` بجانب بند "عروض الأسعار" في القائمة الجانبية (Sidebar).

## 2. القرارات المعمارية والمنطق البرمجي (Key Decisions)
* **سبب مشكلة الـ PDF السابقة وحلها:**
  - المتصفحات الحديثة (خاصة متصفحات الهواتف وGoogle Chrome) عندما يُعطى لها رابط تنزيل مباشر يحمل اسماً بحروف عربية (Non-ASCII)، إما أن تحظر التنزيل كتحذير أمني "Blocked insecure download" أو تقوم بإزالة الامتداد وتحويل الملف إلى امتداد غريب مثل `.bin` أو ملف بدون امتداد.
  - تم الحل بتوليد كائن `Blob` حقيقي في الذاكرة عبر `html2pdf().toPdf().output('blob')`، ثم إنشاء رابط Object URL نظيف مع اسم ملف قياسي: `Quotation-QUO-XXXXXX.pdf`.
  - تم توفير زر بديل ذكي `🖨️ حفظ PDF / طباعة (طريقة الهاتف)` يفتح نافذة النظام الافتراضية، مما يتيح للهاتف حفظ المستند فوراً بصيغة PDF نقية بدقة متناهية (Vector) بدون أي مشاكل.
* **أولوية تجربة الهاتف (Mobile-First):**
  - شاشات الهواتف ضيقة ولا يناسبها وضع جدول المنتجات بجانب بيانات العميل في عمودين. تم اعتماد التبويبات المزدوجة مع شريط الإجمالي العائم، وعرض كروت متجاوبة في قائمة العروض.
