# سجل تعديل: نظام التبويبات المتعددة المخصص لسطح المكتب (Desktop Multi-Tabs System)

* **التاريخ والوقت:** 2026-08-25 20:15
* **الدور المفعل:** Frontend UI & Desktop System Architect
* **الهدف:** بناء نظام تبويبات متطور مخصص لتطبيق سطح المكتب (`isDesktop` / Electron)، يتيح للمحاسب والكاشير فتح شاشات متعددة في نفس الوقت والتنقل بينها فورياً مع الحفاظ الكامل على حالة البيانات والمدخلات (`KeepAlive`)، مع إبقاء الموبايل خفيفاً ونظيفاً بنظامه البسيط.

---

## 1. الملفات المعدلة والجديدة:

* `[NEW]` `backend/resources/js/stores/tabs.js` - مخزن Pinia لإدارة التبويبات المفتوحة، التبويب النشط، والحد الأقصى (12 تابة)، ومصفوفة `cachedViews` لحفظ الحالة.
* `[NEW]` `backend/resources/js/Components/Navigation/DesktopTabsBar.vue` - شريط التبويبات العلوي للديسكتوب بأيقونات الشاشات، أزرار الإغلاق `×`، تبويب لوحة التحكم المثبت، قائمة كليك يمين، واختصارات الكيبورد (`Ctrl+W` و `Ctrl+Tab`).
* `[MODIFIED]` `backend/resources/js/Layouts/SpaLayout.vue` - دمج `<DesktopTabsBar v-if="isDesktop" />` ومزامنة الراوتر مع مخزن التبويبات عبر `watch(route.fullPath)`.
* `[MODIFIED]` `backend/resources/js/App.vue` - تغليف مخرج الشاشات بـ `<KeepAlive v-if="isDesktop" :include="tabsStore.cachedViews" :max="12">` لضمان عدم مسح مدخلات الفواتير عند التبديل بين التابات.
* `[MODIFIED]` `backend/lang/ar/common.php` & `backend/lang/en/common.php` - إضافة مفاتيح الترجمة الموحدة الخاصة بالتبويبات (`close_tab`, `close_other_tabs`, `close_all_tabs`, `refresh_tab`, `new_tab`).

---

## 2. القرارات التقنية والمعمارية:

1. **العزل التام للمنصات (Platform Isolation):** نظام التبويبات يظهر ويعمل حصرياً على سطح المكتب (`isDesktop` / Electron)، بينما يظل الموبايل خفيفاً ومستقلاً بنظام الـ Stack Navigation وشريط التنقل السفلي.
2. **حفظ حالة النماذج والفواتير (`<KeepAlive>`):** تمكين التبديل بين تابة فاتورة مبيعات جارية وتابة كشف حساب عميل أو جرد مخزن دون مسح أي بيانات أو أصناف تم إدخالها.
3. **الحماية من امتلاء الذاكرة (Memory Safeguard):** تحديد سقف أقصى للتبويبات المفتوحة (12 تبويب) مع حذف التبويب الأقدم غير المثبت تلقائياً عند تجاوز الحد.
4. **اختصارات الكيبورد:** دعم `Ctrl + W` لقفل التاب النشط، و `Ctrl + Tab` للتنقل بين التبويبات المفتوحة.
