ملاحظات التصميم — دفع الموبايل

  1. الدفع على الموبايل full-screen sheet (§6.2)، بنفس منطق الديسكتوب: سطور لحد ما المتبقي = 0 (§6.5).
  2. Keypad كبير + فئات كاش مقترحة: كاش بباقي = ضغطة فئة + إتمام (§6.14: ≤ 5 ضغطات).
  3. الباقي بيظهر فوق جنب الصافي بالأخضر علشان الكاشير يشوفه قبل ما يقفل.
  4. الطرق في شريط أفقي قابل للسحب، والآجل مقفول بأيقونة قفل لحد ما يتختار عميل (§6.6).
  5. الجزئي = سطر كاش + سطر آجل، مع رصيد العميل وحده والرصيد بعد البيعة (قرار 2).
  6. زرار الإتمام تحت في منطقة الإبهام، وكل الأهداف ≥ 44px (§6.13).
