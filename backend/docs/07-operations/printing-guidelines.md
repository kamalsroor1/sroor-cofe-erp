# إرشادات ومعايير الطباعة (Printing Guidelines)

دليل شامل لقواعد طباعة الفواتير والإيصالات والتقارير في النظام، يوضح الفروقات الجوهرية بين ورق A4 القياسي ورول الطابعات الحرارية 80mm، وقواعد Print CSS، والمحتويات الإلزامية للفاتورة المطبوعة.

---

## 1. مقارنة شاملة بين نمطي الطباعة (A4 vs Thermal 80mm)

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       Printing Formats Comparison                           │
├──────────────────────────────────────┬──────────────────────────────────────┤
│ 1. Standard A4 Document              │ 2. Thermal 80mm Continuous Receipt   │
│    - Official Sales Invoices         │    - Fast POS Cashier Receipts       │
│    - Customer / Supplier Statements  │    - Daily Cash & Quick Counter Sales│
│    - Inventory & Periodic Reports    │    - Compact, Zero Margin, Roll Paper│
│    - Multi-column detailed table     │    - Essential columns & Bold Totals │
└──────────────────────────────────────┴──────────────────────────────────────┘
```

| وجه المقارنة | قياس المستندات القياسي (A4) | قياس الإيصالات الحرارية (Thermal 80mm) |
| :--- | :--- | :--- |
| **الاستخدام الأساسي** | الفواتير الرسمية للشركات، كشوف الحسابات، تقارير الأرباح والمبيعات. | فواتير الكاشير السريعة في المحلات، إيصالات القبض اليومية، وبون الاستلام. |
| **أبعاد الصفحة** | `210mm × 297mm` (ورق أبيض قياسي). | `80mm` عرض ثابت × طول متغير بحسب عدد أسطر الفاتورة (Continuous Roll). |
| **الهوامش المعتمدة** | `10mm` إلى `15mm` في كافة الجوانب لضمان مظهر رسمي نظيف. | `0mm` إلى `2mm` لاستغلال كامل مساحة الورقة وتوفير الورق الحراري. |
| **حجم ونوع الخطوط** | خط عربي متناسق (10pt إلى 12pt للنصوص، 16pt للعناوين). | خط عريض ومضغوط وواضح التباين بالأبيض والأسود الصرف (9pt إلى 13pt). |
| **الألوان والخلفيات** | يدعم درجات الرمادي والحدود الأنيقة وشعار المتجر الملون أو الرمادي. | أبيض وأسود صرف (Monochrome)؛ ممنوع التدرجات الرمادية الخفيفة لمنع بهتان الطباعة. |
| **مستوى التفاصيل** | يعرض كود الصنف، الوحدة، الكمية، السعر، الخصم، الإجمالي، وتفاصيل الحسابات كاملة. | يعرض اسم الصنف والكمية والسعر والإجمالي بصيغة مدمجة ومختصرة لتسريع الطباعة. |

## 2. القواعد الصارمة لـ Print CSS والتحكم في الصفحة

تتم إدارة مظهر المخرجات الورقية عبر ملفات CSS متخصصة تطبق قواعد `@media print`:

### 2.1 إخفاء عناصر التحكم والشاشات غير المرغوبة
```css
@media print {
    /* إخفاء القوائم الجانبية، الأشرطة العلوية، أزرار النظام، والنوافذ العائمة */
    nav, 
    aside, 
    header, 
    footer.app-footer, 
    .no-print, 
    button, 
    .sidebar, 
    .toast-container {
        display: none !important;
    }

    /* جعل الصفحة بيضاء بالكامل وإزالة أي قيود على الارتفاع والظلال */
    body {
        background: #ffffff !important;
        color: #000000 !important;
        margin: 0 !important;
        padding: 0 !important;
        box-shadow: none !important;
        font-size: 12pt;
    }
}
```

### 2.2 إعدادات حجم وهوامش ورق A4
```css
@page a4-invoice {
    size: A4 portrait;
    margin: 12mm 10mm 12mm 10mm;
}

.a4-print-container {
    page: a4-invoice;
    width: 100%;
    direction: rtl;
}

/* منع انقطاع أسطر الجدول أو تقسيم البنود في منتصف الصفحة */
tr, .invoice-card {
    page-break-inside: avoid;
    break-inside: avoid;
}
```

### 2.3 إعدادات رول الطابعات الحرارية (Thermal 80mm)
```css
@page thermal-receipt {
    size: 80mm auto;
    margin: 0;
}

.thermal-receipt-container {
    page: thermal-receipt;
    width: 72mm; /* ضمان ملاءمة محرك الطباعة داخل الرول */
    margin: 0 auto;
    padding: 2mm;
    direction: rtl;
    font-family: 'Cairo', 'Courier New', monospace;
    font-size: 10pt;
    line-height: 1.3;
}
```

## 3. قائمة المحتويات الإلزامية للفاتورة المطبوعة (Invoice Mandatory Data)

يجب أن تتضمن كل فاتورة مطبوعة صادرة من النظام العناصر التالية مرتبة هرميًا:

```text
┌─────────────────────────────────────────────────────────────┐
│                 هيدر المتجر: الشعار، الاسم، الرقم الضريبي      │
├─────────────────────────────────────────────────────────────┤
│ رقم الفاتورة: #INV-2026-0089 │ التاريخ: 2026-08-08 17:30    │
│ اسم العميل: شركة الأمل الحديثة │ الكاشير: أحمد علي            │
├─────────────────────────────────────────────────────────────┤
│ جدول الأصناف:                                               │
│ [ م | الصنف              | الكمية | السعر   | الإجمالي ]    │
│ [ 1 | كابل نحاس 2 ملم    |  2.000 |  45.000 |  90.000  ]    │
│ [ 2 | مفتاح تشغيل ذكي    |  1.000 |  15.000 |  15.000  ]    │
├─────────────────────────────────────────────────────────────┤
│ المجموع الفرعي: 105.000 د.أ │ الخصم الممنوح: 5.000 د.أ       │
│ صافي الفاتورة النهائي: [ 100.000 د.أ ] (بخط عريض وبارز)     │
│ المبلغ المسدد: 100.000 د.أ │ المتبقي على العميل: 0.000 د.أ  │
├─────────────────────────────────────────────────────────────┤
│         رمز الاستجابة السريعة (QR Code / Barcode)           │
│   سياسة الإرجاع: البضاعة المباعة ترد خلال 14 يومًا بالفاتورة   │
└─────────────────────────────────────────────────────────────┘
```

1. **البيانات التعريفية للمتجر (Header Data):**
   * اسم المحل أو المؤسسة، الشعار (إن وجد)، العنوان التجاري، وأرقام هواتف خدمة العملاء، والرقم الضريبي أو السجل التجاري.
2. **البيانات التوثيقية للفاتورة (Invoice Meta):**
   * رقم الفاتورة الفريد، تاريخ ووقت الإصدار بدقة الدقيقة، نوع السداد (نقدي / آجل / جزئي)، واسم المستخدم / الكاشير الصادر عنه المستند.
3. **بيانات العميل (Customer Details):**
   * اسم العميل، رقم هاتفه، ورصيده السابق أو المتبقي (اختياري حسب رغبة المتجر).
4. **جدول تفاصيل البضائع (Items Details):**
   * تسلسل البند، اسم الصنف، الكمية والوحدة، سعر الوحدة، الخصم الفردي، والإجمالي الصافي لكل سطر.
5. **البيانات المالية الختامية (Financial Summary):**
   * المجموع الفرعي (Subtotal)، الخصم العام، صافي الفاتورة النهائي (Net Total)، المبلغ المدفوع نقدًا، والمبلغ المتبقي كدين.
6. **الرموز والتذييل (Footer & QR Verification):**
   * رمز الاستجابة السريعة (QR Code) المتضمن بيانات الفاتورة للتحقق، وسياسة الاسترجاع والشروط القانونية المعتمدة للمحل.

## 4. إعدادات تفضيل نوع الطباعة الافتراضي (Printer Preference Configuration)

* يتيح النظام لمدير المحل من خلال شاشة `الإعدادات العامة`:
  * اختيار **نوع الطباعة الافتراضي** للمستخدم (`A4` أو `Thermal 80mm`).
  * تفعيل خيار **"الطباعة الفورية التلقائية"** بمجرد الضغط على زر اعتماد الفاتورة (F9) لاستدعاء أمر `window.print()` دون خطوات إضافية.
  * إمكانية إعادة طباعة أي فاتورة سابقة من سجل الفواتير بأي من القياسين في أي وقت.
