# 🚚 توثيق وتحليل صفحة التحويلات المخزنية بين الفروع والمخازن (Stock Transfers)

## 1. النظرة العامة والتحليل التشغيلي:
* **اسم الصفحة:** التحويلات المخزنية وحركة البضائع (Stock Transfers)
* **المسار (Route):** `/stock-transfers`
* **الملف الرئيسي:** `resources/js/views/StockTransfers/StockTransfersView.vue` (منسق نحيف: ~65 سطرًا).
* **الغرض والتحليل التشغيلي:**
  * إدارة وتتبع كافة عمليات نقل البضائع والأصناف بين المخازن المركزية والفروع وسيارات التوزيع.
  * رصد إجمالي حركات النقل عبر 3 مؤشرات KPI (إجمالي أذونات التحويل، التحويلات المنفذة، التحويلات الملغاة).
  * فلاتر بحث متعددة: برقم الإذن، المخزن المصدر، المخزن المستلم، ونطاق التاريخ بواسطة تقويم `BaseDatePicker` (Flatpickr).
  * استعراض تفاصيل إذن التحويل والبنود والكميات والملاحظات والمستخدم المسؤول في نافذة تفاعلية.
  * إلغاء أذونات التحويل الحساسة مع الإلزام بعكس رصيد كافة الأصناف وإرجاعها للمخزن المصدر فوراً داخل `DB::transaction()`.

## 3. عناصر النماذج والواجهات المشتركة المستخدمة:
* `BaseSearchInput.vue`: البحث برقم الإذن أو الملاحظات مع Debounce.
* `BaseSelect.vue`: قوائم اختيار المخزن المصدر والمخزن المستلم.
* `BaseDatePicker.vue`: منتقي التواريخ المتجاوب (Flatpickr) المتوافق 100% مع الوضعين الداكن والفاتح.
* `BaseButton.vue`: زر إنشاء إذن تحويل جديد وأزرار التنقل.
* `ActionMenu.vue`: قائمة الإجراءات العائمة (Floating Teleport) المانعة للقص.
* `MetricCard.vue` / `EmptyState.vue` / `AppModal.vue`.

---

## 4. الاعتماديات والـ APIs:
* **Endpoints:**
  * `GET /api/v1/transfers` (مع فلاتر البحث، المخزن المصدر، المخزن المستلم، التاريخ، والترقيم Pagination).
  * `GET /api/v1/transfers/:id` (جلب تفاصيل إذن التحويل وبنوده).
  * `POST /api/v1/transfers/:id/cancel` (إلغاء التحويل وعكس المخزون داخل Transaction).
  * `GET /api/v1/stores` (جلب قائمة الفروع والمخازن).
* **Actions:** `App\Actions\StockTransfers\CreateStockTransferAction`, `CancelStockTransferAction`.

## 5. فحص التجاوب واللمس والوضعين الداكن والفاتح:
* **الهواتف (360px - 430px):** بطاقات لمسية متجاوبة توضح مسار النقل (من $\rightarrow$ إلى) وزر الإجراءات يفتح كـ Bottom Action Sheet من أسفل الشاشة.

* **الوضع الداكن والفاتح:** معالجة كاملة لتباين عناصر التقويم وقوائم الأشهر وخلفيات الحقول.
