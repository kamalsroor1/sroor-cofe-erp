# بنية واجهة المستخدم (Frontend Architecture)

توثيق معماري شامل لواجهة المستخدم للنظام، يشرح تكامل Livewire 4 مع Blade و Alpine.js، وتوزيع المكونات، ومعايير الفصل الحاسم بين التفاعلات المحلية والطلبات الخادمة، وهيكلة الـ Layouts.

---

## 1. فلسفة الواجهة والتقنيات الأساسية (Frontend Philosophy)

يعتمد النظام على نهج **HTML-First Dynamic Architecture** عبر المزج المتناغم بين:
1. **Blade Templates:** لهيكلة صفحات الـ HTML النظيفة وتمرير البيانات.
2. **Laravel Livewire 4:** لإدارة الحالة (State Management)، التفاعل الحي مع الخادم، العمليات الحسابية المباشرة، وحفظ البيانات بدون كتابة أكواد JavaScript معقدة.
3. **Alpine.js:** لتوفير استجابة فورية بدون أي تأخير للشبكة في التفاعلات البصرية الخفيفة (Client-Side Micro-interactions).
4. **Tailwind CSS & Flowbite:** لبناء واجهات عصرية متجاوبة ومتناسقة بالكامل مع دعم الوضعين الليلي والنهاري ودعم اللغة العربية (RTL).

---

## 2. القواعد الحاسمة: متى نستخدم Livewire ومتى نستخدم Alpine.js؟

لضمان أعلى سرعة واستجابة وتجنب إرهاق السيرفر بطلبات غير ضرورية، تم وضع قواعد حاسمة لفصل المهام:

```text
┌─────────────────────────────────────────────────────────────┐
│             Decision Tree: Alpine.js vs Livewire            │
└──────────────────────────────┬──────────────────────────────┘
                               │
               هل التفاعل يحتاج بيانات من قاعدة البيانات
               أو ينفذ عملية محاسبية/أمنية؟
                               │
                ├─── نعم ───► [ استخدام Livewire 4 ]
                │             (بحث أصناف، حساب إجمالي، حفظ فاتورة، ترحيل مخزون)
                │
                └─── لا  ───► [ استخدام Alpine.js ]
                              (فتح Dropdown، إغلاق Modal، تبديل Dark Mode، فلترة جدول محلي)
```

| الميزة / الإجراء المطلوب | الأداة المختارة | السبب والمعيار التقني |
| :--- | :--- | :--- |
| **فتح وإغلاق القوائم المنسدلة (Dropdowns)** | **Alpine.js** (`x-data`, `x-show`) | تفاعل بصري محلي بحت في المتصفح لا يحتاج للاتصال بالخادم. |
| **إظهار وإخفاء النوافذ المنبثقة (Modals)** | **Alpine.js** | استجابة فورية عند النقر لفتح أو إغلاق النافذة بدون Latency. |
| **البحث الحي عن الأصناف والعملاء** | **Livewire 4** (`wire:model.live.debounce`) | يحتاج إلى استعلام سريع ومباشر في قاعدة البيانات وتطبيق الفهارس. |
| **إضافة صنف لجدول الفاتورة وحساب السعر** | **Livewire 4** | يحتاج للتحقق من المخزون، جلب التكلفة، وجلب آخر سعر بيع للعميل. |
| **تبديل الوضع الليلي (Dark/Light Mode)** | **Alpine.js** (`localStorage`) | تعديل فئة `class="dark"` في كائن HTML محليًا وفورًا. |
| **التحقق من صحة المدخلات (Real-time Validation)** | **Livewire 4** | تطبيق قواعد التحقق الصارمة للباك إند (Laravel Form Request Rules). |
| **تطبيق الخصم واحتساب الصافي التراكمي** | **Livewire 4** | إجراء العمليات الحسابية المالية الدقيقة بواسطة `bcmath` على الخادم. |
| **تبديل التبويبات البصرية (UI Tabs)** | **Alpine.js** | تبديل إظهار المحتوى التفاعلي الثابت في نفس الصفحة دون تحميل. |

## 3. تقسيم وهيكلة مكونات Livewire المقترحة (Component Breakdown)

تم تصميم مكونات Livewire لتكون مستقلة، مركزة، وقابلة لإعادة الاستخدام في مختلف الشاشات:

```text
app/Livewire/
├── Invoices/
│   ├── InvoiceCreate.php          # شاشة إنشاء فواتير البيع الحية (POS & Sales)
│   ├── InvoiceList.php            # جدول واستعراض فواتير البيع والفلترة
│   └── InvoiceShow.php            # استعراض تفاصيل الفاتورة وإدارتها
├── Purchases/
│   ├── PurchaseCreate.php         # شاشة فواتير الشراء وتوريد الأصناف
│   └── PurchaseList.php           # استعراض فواتير المشتريات
├── Items/
│   ├── ItemList.php               # دليل الأصناف وإدارة المخزون والتعديل
│   └── ItemQuickCreateModal.php   # نافذة سريعة لإضافة صنف جديد أثناء البيع
├── Customers/
│   ├── CustomerList.php           # دليل العملاء وأرصدتهم
│   └── CustomerStatement.php      # كشف حساب العميل التفاعلي
├── Suppliers/
│   ├── SupplierList.php           # دليل الموردين
│   └── SupplierStatement.php      # كشف حساب المورد
├── Payments/
│   └── PaymentModal.php           # نافذة تسجيل سندات القبض والدفعات المجزأة
├── Returns/
│   └── ReturnModal.php            # نافذة تسجيل المرتجع الجزئي والكامل
└── Dashboard/
    ├── DashboardStats.php         # بطاقات الإحصائيات اللحظية ومبيعات اليوم
    └── LowStockWidget.php         # جدول تنبيهات النواقص ورصيد الأمان
```

## 4. استراتيجية التنقل بواسطة `wire:navigate`

لتوفير تجربة استثنائية تحاكي تطبيقات SPA السريعة وتمنع وميض الصفحة الكامل (Full Page Flickering):

* **متى يُستخدم `wire:navigate`؟**
  * في جميع روابط القائمة الجانبية (Sidebar Links).
  * في أزرار التنقل الأساسية بين الشاشات (مثال: الانتقال من قائمة الفواتير إلى إنشاء فاتورة جديدة).
  * في روابط الانتقال لملفات العملاء، الأصناف، والتقارير.
* **متى لا يُستخدم؟**
  * روابط تصدير ملفات Excel و PDF (لأنها تتطلب تحميل مباشر لملفات ثنائية Binary Downloads).
  * نوافذ وأوامر فتح شاشة الطباعة المباشرة (`window.print()`).
  * روابط تسجيل الخروج وتغيير الجلسات الجذرية.

## 5. هيكلة قوالب Blade وتخطيطات الصفحات (Blade Layouts Structure)

تم تنظيم الـ Layouts لتخدم أغراض الاستخدام المختلفة، خصوصًا فصل العرض التفاعلي عن عروض الطباعة:

```text
resources/views/
├── layouts/
│   ├── app.blade.php              # التخطيط العام للنظام (Sidebar, Topbar, Main Shell)
│   ├── guest.blade.php            # تخطيط صفحات الدخول واستعادة الحساب (Breeze)
│   ├── print-a4.blade.php         # قالب طباعة المستندات والفواتير على ورق A4
│   └── print-thermal.blade.php    # قالب طباعة الإيصالات الحرارية (80mm Continuous Roll)
├── components/
│   ├── alert.blade.php            # مكون التنبيهات الموحد
│   ├── button.blade.php           # أزرار النظام المعقمة
│   ├── input.blade.php            # حقول الإدخال المتوافقة مع Dark/Light و RTL
│   ├── modal.blade.php            # هيكل النوافذ المنبثقة المدعومة بـ Alpine.js
│   └── table.blade.php            # الجداول المتجاوبة مع الموبايل
└── livewire/                      # قوالب العرض الخاصة بمكونات Livewire
```

### 5.1 وصف الـ Layouts الأساسية:

1. **`layouts/app.blade.php` (General Layout):**
   * يحتوي على الهيدر العلوي، القائمة الجانبية المتجاوبة (Sidebar)، شريط التنبيهات، حاوية الإشعارات (Toasts)، ومدير الـ Assets (Tailwind & Flowbite).
2. **`layouts/print-a4.blade.php` (A4 Print Layout):**
   * خالي تمامًا من السايدبار، الأزرار، والنافبار.
   * يحتوي على كود `@page { size: A4 portrait; margin: 12mm; }`، وهيدر تجاري للمحل، وجداول مفصلة مع شعار المتجر.
3. **`layouts/print-thermal.blade.php` (Thermal 80mm Print Layout):**
   * مخصص لطابعات البون والإيصالات الحرارية: `@page { size: 80mm auto; margin: 0; }`.
   * خطوط واضحة، حجم نصوص مدمج ومضغوط، عرض ثابت 72mm-80mm، ورمز QR وباركود الفاتورة.
4. **`layouts/guest.blade.php` (Guest Layout):**
   * شاشات تسجيل الدخول وتوثيق Breeze، بتصميم نظيف ومركزي.
