# إرشادات تجربة المستخدم (UX Guidelines)

توثيق تفصيلي لمبادئ تصميم تجربة المستخدم (UX)، سيناريوهات الاستخدام الأساسية (User Flows)، ومراعاة سرعة العمل، والكاشير، وتجربة الموبايل والعمل بيد واحدة.

---

## 1. المبادئ الأساسية لتجربة المستخدم (Core UX Principles)

1. **السرعة الفائقة وتقليل النقرات (Minimal Clicks):**
   * يجب ألا يستغرق إصدار فاتورة بيع نقدية كاملة أكثر من 10 إلى 15 ثانية.
   * التركيز التلقائي (Autofocus) في حقل البحث عن الأصناف بمجرد فتح الشاشة.
2. **الاعتماد الكامل على لوحة المفاتيح والباركود (Keyboard-First POS):**
   * دعم اختصارات لوحة المفاتيح للتنقل بين الأسطر، تعديل الكمية (F2 أو Enter)، وتطبيق الخصم وحفظ الفاتورة (Ctrl+Enter / F9).
   * التوافق مع قارئات الباركود بحيث يضاف الصنف لجدول الفاتورة تلقائيًا بمجرد مسح الكود.
3. **الشفافية والحسابات اللحظية المباشرة (Instant Real-time Feedback):**
   * إظهار مجاميع الفاتورة، الخصومات، والربح التقديري (للمدير) فور إدخال أي رقم بدون الحاجة للنقر على زر "احسب".
4. **منع الأخطاء البشرية قبل حدوثها (Proactive Error Prevention):**
   * تنبيه الكاشير فورًا بلون أحمر بارز عند محاولة بيع كمية تتجاوز الرصيد المتاح.
   * طلب تأكيد بصري واضح قبل عمليات الإلغاء أو المرتجعات.

---

## 2. مسارات وسيناريوهات الاستخدام الأساسية (Core User Flows)

### 2.1 سيناريو إنشاء فاتورة بيع جديدة (Sales Invoice Flow)

```mermaid
flowchart LR
    A[1. فتح شاشة الفاتورة] --> B[2. اختيار العميل أو كاش افتراضي]
    B --> C[3. مسح الباركود أو كتابة اسم الصنف]
    C --> D[4. تعديل الكمية / الخصم إن لزم]
    D --> E[5. إدخال المبلغ المدفوع]
    E --> F[6. حفظ واعتماد الفاتورة F9]
    F --> G[7. طباعة فورية A4 أو Thermal 80mm]
```

* **تفاصيل الخطوات:**
  1. يُفتح نموذج الفاتورة ومؤشر الفأرة داخل مربع بحث الأصناف تلقائيًا.
  2. إذا كان العميل نقديًا، يتم اختياره افتراضيًا كـ `عميل نقدي عام`.
  3. بمجرد اختيار الصنف، يظهر آخر سعر بيع تم التعامل به مع هذا العميل لضمان الاستمرارية.
  4. تظهر تفاصيل الرصيد المتاح لكل صنف بلون أخضر أو تحذيري إذا كان الرصيد يقترب من النفاد.
  5. عند الضغط على زر الاعتماد، تُقفل الأزرار فورًا وتظهر حالة معالجة (Loading Spinner) لمنع النقر المزدوج.

---

### 2.2 سيناريو تسجيل سند قبض ودفعة مالية (Payment Collection Flow)

1. فتح قائمة العملاء أو كشف حساب العميل المعني.
2. النقر على زر **"تسجيل دفعة / سند قبض"** المتاح بجانب رصيد العميل أو الفاتورة الآجلة.
3. تفتح نافذة سريعة (Slide-over Modal) توضح الرصيد الإجمالي المستحق على العميل.
4. إدخال المبلغ المحصل، طريقة الدفع (كاش، تحويل بنكي)، وتاريخ الاستلام.
5. حفظ السند وتحديث الرصيد اللحظي للعميل وطباعة إيصال استلام للمبلغ فورًا.

---

### 2.3 سيناريو تسجيل فاتورة شراء وتوريد مخزني (Purchase & Stock In Flow)

1. اختيار المورد من القائمة المنسدلة الذكية.
2. إضافة الأصناف الموردة مع تحديد الكميات وأسعار التكلفة الجديدة.
3. يعرض النظام مقارنة بين سعر التكلفة الجديد وسعر التكلفة المسجل سابقًا في النظام.
4. إدخال المبالغ المدفوعة للمورد إن وجدت وتحديد نوع الفاتورة (نقدي أو آجل).
5. حفظ الفاتورة؛ مما يؤدي لزيادة أرصدة الأصناف في المخازن، وتحديث متوسط التكلفة، وإضافة مستحقات المورد تلقائيًا.

---

### 2.4 سيناريو عمل مرتجع مبيعات جزئي (Partial Sales Return Flow)

1. البحث عن الفاتورة الأصلية بواسطة رقم الفاتورة أو اسم العميل.
2. النقر على زر **"إنشاء مرتجع مبيعات"** المخصص في تفاصيل الفاتورة.
3. يعرض النظام جدول أصناف الفاتورة الأصلية والكميات التي تم شراؤها والكميات المتاحة للإرجاع.
4. يحدد المستخدم الكمية المرتجعة من صنف معين ويكتب سبب الإرجاع.
5. اعتماد المرتجع؛ فيقوم النظام بإعادة الكمية للمخزن، وخصم قيمتها من حساب العميل، وتحديث تقارير الأرباح والمبيعات.

---

### 2.5 سيناريو مراجعة كشف حساب العميل والديون المتأخرة (Statement & Debt Audit Flow)

1. الانتقال إلى شاشة العميل واختيار تبويب **"كشف الحساب"**.
2. تحديد نطاق التاريخ (من تاريخ → إلى تاريخ) أو الضغط على اختصارات سريعة: `هذا الشهر`، `آخر 3 أشهر`، `الكل`.
3. عرض جدول متكامل بالترتيب الزمني: الفواتير، المدفوعات، المرتجعات، والرصيد المتحرك بعد كل حركة.
4. توفير إمكانية تصدير الكشف فورًا كملف **PDF** أو **Excel** أو طباعته على ورق **A4**.

---

## 3. معايير وتجربة الموبايل والعمل بيد واحدة (Mobile-First & One-Handed POS)

لتوفير تجربة استثنائية للكاشير أو التاجر عند العمل عبر الهواتف الذكية وأجهزة التابلت:

1. **مناطق التفاعل في أسفل الشاشة (Bottom Thumb Zone):**
   * وضع شريط الإجراءات الرئيسي (أزرار: حفظ الفاتورة، الحسابات، الإجمالي) مثبتًا في أسفل الشاشة (Sticky Bottom Bar) لتسهيل الوصول إليها بإبهام اليد الواحدة.
2. **أبعاد لمس مريحة ومناسبة للإصبع (Touch Targets):**
   * جعل أدنى ارتفاع لجميع الأزرار القابلة للمس بين **44px إلى 48px**.
   * تباعد كافٍ بين أزرار الحذف وأزرار التعديل لمنع الضغطات الخاطئة على الشاشات الصغيرة.
3. **تصميم النماذج والجداول المتجاوبة (Card-based Mobile Views):**
   * تحويل جداول الفواتير الطويلة إلى بطاقات واضحة (Cards Layout) على شاشات الموبايل تُبرز اسم الصنف والكمية والإجمالي بخط كبير وواضح.
4. **لوحات مفاتيح رقمية محسنة (Optimized Numeric Keypads):**
   * تفعيل `inputmode="decimal"` أو `type="number"` في حقول الكميات والأسعار لفتح لوحة الأرقام الكبيرة تلقائيًا على أجهزة Android و iOS.
