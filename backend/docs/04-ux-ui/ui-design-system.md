# نظام التصميم والهوية البصرية (UI Design System)

توثيق نظام التصميم، لوحات الألوان، الخطوط العربية المدعومة، قواعد المحاذاة والاتجاه (RTL)، وحالات المكونات المختلفة في بيئتي الوضع الفاتح والداكن.

---

## 1. لوحة الألوان (Color Palette & Theme Tokens)

تم بناء درجات الألوان بالاعتماد على **Tailwind CSS** ومكتبة **Flowbite UI** لتوفير تباين بصري ممتاز، وراحة للعين، ودقة في إبراز الحالات المالية والمخزنية.

```text
┌─────────────────────────────────────────────────────────────┐
│                   Theme Color Palette                       │
├───────────────────┬───────────────────┬─────────────────────┤
│  Primary (Blue)   │  Success (Emerald)│  Warning (Amber)    │
│  Main actions,    │  Payments, stock  │  Low stock, partial │
│  buttons, links   │  deposits, profits│  payments, debts    │
├───────────────────┼───────────────────┼─────────────────────┤
│  Danger (Rose)    │  Dark Shell       │  Light Shell        │
│  Cancellations,   │  bg-gray-900      │  bg-gray-50         │
│  returns, errors  │  text-gray-100    │  text-gray-900      │
└───────────────────┴───────────────────┴─────────────────────┘
```

| نوع الاستخدام / العنصر | فئات الوضع الفاتح (Light Mode) | فئات الوضع الداكن (Dark Mode) |
| :--- | :--- | :--- |
| **خلفية الصفحة العامة** | `bg-gray-50` | `bg-gray-900` |
| **خلفية البطاقات والجداول** | `bg-white border-gray-200` | `bg-gray-800 border-gray-700` |
| **اللون الأساسي (Primary)** | `bg-blue-600 hover:bg-blue-700 text-white` | `bg-blue-600 hover:bg-blue-500 text-white` |
| **حالة النجاح والتحصيل (Success)**| `bg-emerald-500 text-white / text-emerald-600` | `bg-emerald-600 text-white / text-emerald-400`|
| **حالة التنبيه والمخزون المنخفض (Warning)**| `bg-amber-500 text-white / text-amber-600` | `bg-amber-600 text-white / text-amber-400` |
| **حالة الخطر والإلغاء (Danger)**| `bg-rose-600 hover:bg-rose-700 text-white` | `bg-rose-600 hover:bg-rose-500 text-white` |
| **النصوص الأساسية** | `text-gray-900` | `text-gray-100` |
| **النصوص الثانوية والتلميحات** | `text-gray-500` | `text-gray-400` |

## 2. الخطوط والطباعة العربية (Typography & Arabic Fonts)

* **الخط المقترح المعتمد:** خط **Cairo** أو **Tajawal** (من مكتبة Google Fonts) لما يتميز به من وضوح شديد للأرقام العربية والإنجليزية وسهولة القراءة في الفواتير والجداول السريعة.
* **الأوزان المستخدمة (Font Weights):**
  * `font-normal` (400): للنصوص العادية وشروح البنود.
  * `font-medium` (500): لعناوين الجداول وحقول الإدخال.
  * `font-semibold` (600): لعناوين البطاقات وأسماء الأصناف.
  * `font-bold` (700): للأرقام المالية الكبيرة، الإجماليات، وأزرار الاعتماد.
* **مقياس الأحجام (Font Scale):**
  * العناوين الكبرى للشاشات: `text-2xl font-bold` (24px).
  * إجماليات الفواتير والأرقام البارزة: `text-3xl font-extrabold` (30px).
  * نصوص الجداول العامة: `text-sm font-medium` (14px).
  * البيانات الثانوية وتواريخ العمليات: `text-xs` (12px).

## 3. قواعد وتوافق اللغة العربية (RTL Design Guidelines)

1. **الاتجاه المنطقي للمحاذاة:**
   * استخدام فئات Tailwind المنطقية مثل `text-start` و `text-end` بدلاً من `text-left` و `text-right` الثابتة.
   * استخدام `ms-` (Margin Start) و `me-` (Margin End) و `ps-` / `pe-` للمسافات والحشوات.
2. **محاذاة الأرقام المالية والكميات:**
   * تتم محاذاة أسماء الأصناف وتفاصيل النصوص إلى جهة اليمين (`text-start`).
   * بينما تُحاذى الأرقام المالية، الأسعار، والإجماليات في الجداول جهة اليسار (`text-end` في سياق RTL) لتسهيل قراءة ومقارنة المراتب العشرية والكسور بدقة تامة.
3. **انعكاس اتجاه الأيقونات (Icon Flipping):**
   * أسهم التنقل، أزرار الرجوع، وأيقونات الخطوات تنعكس تلقائيًا في اتجاه اليمين لتتوافق مع السياق العربي الطبيعي.

## 4. مقاسات عناصر اللمس والأزرار (Touch Targets & Sizing)

لتلبية متطلبات بيئات العمل اليومية في المتاجر وأجهزة الهواتف الذكية وأجهزة الكاشير التي تعمل باللمس:

| المكون (Component) | الارتفاع الموصى به | الحشوة (Padding) | الاستخدام الأساسي |
| :--- | :--- | :--- | :--- |
| **الزر الأساسي (Primary Button)** | `h-12` (48px) | `px-5 py-2.5` | أزرار "حفظ الفاتورة"، "اعتماد الشراء"، "تسجيل دفعة" |
| **أزرار الأسطر والجداول (Table Action Buttons)** | `h-10` (40px) | `px-3 py-2` | أزرار "عرض"، "طباعة"، "إضافة سطر" |
| **حقول الإدخال والبحث (Input Fields)** | `h-12` (48px) | `px-4 py-2.5 text-base` | حقول البحث عن الأصناف والعملاء والكميات |
| **عناصر الاختيار (Checkboxes & Radios)** | `w-5 h-5` (20px) | مع مساحة نقر خارجية `p-2` | خيارات التفعيل والتعطيل وتحديد نوع السداد |

## 5. حالات الواجهة المختلفة (UI States & Feedback)

```text
┌──────────────────────────────────────────────────────────────────┐
│                      State Feedback System                       │
├─────────────────┬────────────────────┬───────────────────────────┤
│  Loading State  │  Empty State       │  Error / Alert State      │
│  wire:loading   │  Empty table card  │  Field validation & toast │
│  Spinner/Shimmer│  with action button│  modal for rollback       │
└─────────────────┴────────────────────┴───────────────────────────┘
```

1. **حالة التحميل والمعالجة (Loading States):**
   * استخدام `wire:loading` مع تعطيل الأزرار تلقائيًا (`wire:loading.attr="disabled"`) لمنع تكرار طلبات الاعتماد.
   * إظهار تأثير الوميض والتحميل الهيكلي (Skeleton Loader) أثناء تحميل جداول التقارير الكبيرة أو تصفية الحسابات.
2. **حالة القوائم الفارغة (Empty States):**
   * عند عدم وجود فواتير أو أصناف مسجلة، يظهر رسم توضيحي نظيف، مع رسالة ترحيبية وزر بارز كبير يدعو لإضافة أول عنصر (مثال: "لا توجد فواتير مبيعات مسجلة اليوم - اضغط لإنشاء فاتورة جديدة").
3. **حالة الخطأ والتحقق (Error & Validation States):**
   * إبراز الحقول غير الصحيحة بحدود حمراء `border-rose-500` مع ظهور نص رسالة الخطأ أسفل الحقل فورًا.
   * عند فشل المعاملة بسبب عدم توفر المخزون، تظهر رسالة تنبيه عائمة بلون أحمر داكن تشرح سبب التراجع.
4. **حالة النجاح والإشعار اللحظي (Success Toasts):**
   * ظهور شريط إشعار أخضر صغير ومتحرك في أعلى الشاشة يختفي تلقائيًا بعد 3 ثوانٍ (Alpine Toast) عند نجاح الحفظ أو تسجيل السندات.
