# وصف الشاشات والمخططات الهيكلية (Screens & Wireframes Description)

وصف نصي وهيكلي تفصيلي لكافة الشاشات الرئيسية في النظام، يوضح توزيع العناصر البصرية، التسلسل الهرمي، ما يظهر أولاً، والتكيف مع شاشات الكمبيوتر والهواتف الذكية.

---

## 1. شاشة لوحة التحكم الرئيسية (Dashboard Screen)

تعتبر مركز القيادة اليومي للتاجر، وتفتح فور تسجيل الدخول لتعطي نظرة شاملة على النشاط التجاري دون الحاجة للتنقل في القوائم.

### 1.1 التخطيط الهيكلي للشاشة (ASCII Wireframe)

```text
+-----------------------------------------------------------------------------------------------+
| [ Logo ]  نظام إدارة الفواتير والمخزون       [ بحث سريع ]      [ الوضع الليلي ] [ المستخدم ]  |
+-----------------------------------------------------------------------------------------------+
| [القائمة الجانبية] | [ بطاقة 1: مبيعات اليوم ]  [ بطاقة 2: عدد الفواتير ]  [ بطاقة 3: المحصل اليوم ]  |
| ├── الرئيسة      |      5,450.000 د.أ               18 فاتورة               3,200.000 د.أ     |
| ├── الفواتير     +----------------------------------------------------------------------------+
| ├── الأصناف      | [ بطاقة 4: المبيعات الآجلة] [ بطاقة 5: إجمالي الأرباح] [ بطاقة 6: ديون متأخرة]   |
| ├── العملاء      |      2,250.000 د.أ               1,120.000 د.أ           14,800.000 د.أ    |
| ├── الموردون     +----------------------------------------------------------------------------+
| ├── المشتريات    | [ تنبيهات المخزون المنخفض (Low Stock) ] | [ آخر فواتير البيع المصدرة ]             |
| ├── التقارير     |  - كابل كهرباء 2 ملم (المتبقي: 2 كرتونة)|  - #INV-1004 | عميل نقدي | 120.000 د.أ     |
| └── الإعدادات    |  - مفتاح إضاءة ذكي  (المتبقي: 1 قطعة)  |  - #INV-1003 | شركة الأمل | 850.000 د.أ    |
+-----------------------------------------------------------------------------------------------+
```

* **ما يظهر أولاً:** بطاقات الإحصائيات الست السريعة في أعلى الصفحة.
* **الترتيب والتوزيع:**
  1. شريط إحصائي سريع لأرقام اليوم (مبيعات، فواتير، تحصيل، أرباح).
  2. قسم المتابعة الائتمانية والديون المتأخرة وتنبيهات الاستحقاق.
  3. جدولان جانبيان متوازيان: جدول تنبيهات انخفاض المخزون عن الحد الأدنى وجدول آخر العمليات الصادرة.
* **على الموبايل:** تترتب البطاقات عموديًا في شريط علوي قابل للتمرير أو في شبكة من عمودين، يليها جدول التنبيهات.

## 2. شاشة إنشاء فواتير البيع (Sales Invoice / POS Screen)

الشاشة الأكثر استخدامًا؛ صُممت لتكون سريعة وفائقة الاستجابة وتركز على الكيبورد لتقليل وقت انتظار العميل.

### 2.1 التخطيط الهيكلي للشاشة (ASCII Wireframe)

```text
+-----------------------------------------------------------------------------------------------+
|  إنشاء فاتورة بيع جديدة | رقم: INV-2026-0089 | التاريخ: 2026-08-08 | الكاشير: أحمد             |
+-----------------------------------------------------------------------------------------------+
| [اختيار العميل: عميل نقدي عام ▼] [رصيد العميل السابق: 0.000] [نوع السداد: (•) نقدي ( ) آجل]    |
+-----------------------------------------------------------------------------------------------+
| [ حقل البحث السريع عن الصنف أو مسح الباركود (Autofocus) 🔍 ________________________ ] [إضافة] |
+-----------------------------------------------------------------------------------------------+
| م | كود الصنف | اسم الصنف             | الكمية | سعر الوحدة | الخصم  | الإجمالي الصافي | إجراء |
|---|-----------|-----------------------|--------|------------|--------|-----------------|-------|
| 1 | ITM-0012  | زيت محرك تخليقي 5W30  |  2.000 |    45.000  |  0.000 |         90.000  | [حذف] |
| 2 | ITM-0045  | فلتر هواء أصلي        |  1.000 |    15.000  |  2.000 |         13.000  | [حذف] |
+-----------------------------------------------------------------------------------------------+
| [قسم الحسابات السفلية والإجمالي]                                                              |
| المجموع الفرعي: 103.000 | خصم الفاتورة: [ 3.000 ] | الصافي النهائي: [ 100.000 د.أ ]             |
| المبلغ المدفوع: [ 100.000 ] | المتبقي على العميل: 0.000                                       |
+-----------------------------------------------------------------------------------------------+
| [ زر حفظ واعتماد الفاتورة (F9) 💾 ]  [ زر طباعة A4 🖨️ ]  [ زر طباعة حراري 80mm 🧾 ]  [إلغاء]  |
+-----------------------------------------------------------------------------------------------+
```

* **ما يظهر أولاً:** حقل البحث عن الأصناف ومؤشر الفأرة داخله تلقائيًا.
* **الترتيب الهرمي:**
  1. شريط بيانات العميل ونوع الفاتورة.
  2. حقل البحث والباركود المباشر.
  3. جدول أسطر الأصناف مع إمكانية تعديل الكميات والأسعار والخصم الفردي مباشرة داخل الجدول.
  4. شريط الإجماليات والخصم العام وحساب المتبقي.
  5. شريط الأزرار الكبيرة للاعتماد والطباعة السريعة.
* **على الموبايل:** تظهر الأصناف المضافة في صورة بطاقات مكدسة، مع تثبيت شريط الإجمالي وزر الحفظ في أسفل الشاشة (Sticky Bottom Action Bar).

## 3. شاشة إدارة الأصناف والمخزون (Items & Stock Screen)

تتيح جرد ومتابعة الأصناف والأسعار وتعديل بطاقة الصنف ومراجعة التكاليف.

### 3.1 التوزيع والعناصر
1. **شريط الأدوات العلوي:** زر "إضافة صنف جديد"، زر "إيداع مخزون يدوي"، حقل بحث فوري، وفلتر (الكل / منخفض المخزون / المعطل).
2. **جدول الأصناف الرئيسي:**
   * الأعمدة: كود الصنف، اسم الصنف، الوحدة، الرصيد الحالي (ملون بالأخضر إذا آمن وبالأصفر/الأحمر إذا وصل للحد الأدنى)، سعر التكلفة (Cost Price)، سعر البيع الافتراضي، متوسط التكلفة (WAC)، حالة الصنف (مفعل/معطل)، وأزرار الإجراءات (تعديل، كشف حركة المخزون، تعطيل).
3. **نافذة كشف حركة المخزون للصنف (Stock Movement Modal):**
   * جدول تاريخي يوضح كل حركة خروج ودخول وسعرها والمستند ورصيد الصنف بعد الحركة.

## 4. شاشة العملاء والموردين وكشف الحساب (Directory & Statement Screen)

### 4.1 شاشة الدليل (Directory View)
* بطاقات أو جدول منظم بالأسماء، أرقام الهواتف، العناوين، الأرصدة الحالية (المديونيات)، وزر سريع لإصدار فاتورة أو تسجيل سند قبض.

### 4.2 شاشة كشف الحساب التفاعلي (Statement of Account View)
* **رأس الكشف:** بطاقة العميل/المورد، إجمالي التعاملات، الرصيد الافتتاحي، والرصيد الحالي المستحق.
* **شريط التصفية:** محدد التاريخ (من تاريخ → إلى تاريخ)، أزرار الفلترة السريعة (الشهر الحالي، كل العمليات)، وزر تصدير Excel وزر طباعة A4.
* **جدول كشف الحساب التراكمي:**
  * الأعمدة: التاريخ، نوع المستند ورقم الحركة (فاتورة بيع، سند قبض، مرتجع مبيعات)، البيان، مدين (عليه)، دائن (له)، والرصيد المتحرك التراكمي بعد كل حركة.

---

## 5. شاشة فواتير الشراء والمرتجعات (Purchases & Returns Screen)

### 5.1 شاشة فواتير الشراء (Purchase Invoices)
* تماثل شاشة فواتير البيع ولكنها موجهة لإدخال كميات التوريد وأسعار التكلفة الجديدة، مع تحديد المورد والمبلغ المدفوع له، ومطابقة رقم الفاتورة الورقية الخاصة بالمورد.

### 5.2 شاشة المرتجعات (Returns Screen)
* تتيح اختيار الفاتورة الأصلية، ثم استعراض الأصناف المباعة، مع تحديد الكمية المراد إرجاعها فقط (المرتجع الجزئي)، وتحديد سبب المرتجع وطريقة تسوية الحساب (خصم من رصيد العميل أو رد نقدي فوري).

---

## 6. شاشة التقارير والتحليلات المالية (Financial & Profit Reports)

* **التبويبات العلوية:** تقرير المبيعات | تقرير الأرباح والتكاليف | تقرير حركة المخزون | تقرير تحصيل الديون.
* **لوحة المؤشرات:** إجمالي الإيرادات، إجمالي تكلفة البضاعة المباعة (COGS)، صافي الأرباح المحققة، ومتوسط هامش الربح (%).
* **جدول التفاصيل التحليلي:** استعراض الأرباح حسب الصنف الأكثر مبيعًا، الأرباح حسب العميل، والأرباح حسب كل فاتورة بيع فردية مع خيارات التصدير (PDF / Excel).

---

## 7. شاشات قوالب الطباعة (Print Views)

### 7.1 قالب الطباعة القياسي (A4 Print Layout)
* تصميم رسمي أنيق يتضمن شعار المتجر وبياناته ورقم التسجيل الضريبي في الهيدر، جدول الأصناف بتفاصيل واضحة وخط مقروء، جدول ملخص الحسابات والخصومات والمدفوعات والمتبقي، وفوتر يحتوي على شروط البيع وسياسة المرتجعات والتوقيعات.

### 7.2 قالب الطباعة الحراري (Thermal 80mm Receipt)
* تصميم طولي مدمج (Compact Receipt) بدون مساحات بيضاء زائدة؛ يبدأ باسم المحل ورقم الهاتف، ثم رقم وتاريخ الفاتورة واسم الكاشير، يليه جدول مبسط (الصنف، الكمية، السعر، الإجمالي)، ثم الصافي النهائي بخط عريض وواضح، وطريقة السداد، مع باركود / QR Code الفاتورة في النهاية.
