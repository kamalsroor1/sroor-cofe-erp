# قاموس المصطلحات (Project Glossary)

دليل شامل للمصطلحات التقنية والمالية والمخزنية المستخدمة في نظام إدارة الفواتير والمخزون، مع شرح دقيق ومبسط لكل مفهوم باللغة العربية.

---

## 1. مصطلحات المخزون وحركة البضائع (Stock & Inventory Terms)

| المصطلح بالإنجليزية | المصطلح بالعربية | الشرح والتعريف البرمجي والتشغيلي |
| :--- | :--- | :--- |
| **Stock In** | توريد / إدخال مخزني | حركة تؤدي إلى زيادة الكمية المتوفرة من الصنف في المخزن، وتنتج عن: فاتورة شراء، مرتجع مبيعات، تسوية بالزيادة، أو إيداع مخزني افتتاحي. |
| **Stock Out** | صرف / إخراج مخزني | حركة تؤدي إلى خصم الكمية من رصيد الصنف في المخزن، وتحدث تلقائيًا وبشكل فوري عند اعتماد فاتورة البيع أو تسوية بالعجز أو مرتجع مشتريات. |
| **Stock Movement** | حركة المخزون | سجل دائم وغير قابل للتعديل يوثق كل تغير يطرأ على رصيد أي صنف (مصدر الحركة، الكمية، الرصيد قبل وبعد الحركة، التكلفة، التاريخ، والمستخدم). |
| **Minimum Stock Level** | الحد الأدنى للمخزون | رقم حد الأمان المعين للصنف؛ عندما يصل الرصيد الفعلي لهذا الرقم أو يقل عنه، يُصدر النظام تنبيهًا فوريًا بنقص المخزون (Low Stock Alert). |
| **Stock Deposit** | إيداع مخزون يدوي | عملية إضافة رصيد بضاعة للمستودع خارج دورة فواتير الشراء، مثل الأرصدة الافتتاحية للمحل أو التعديلات اليدوية المصرح بها. |
| **Stock Adjustment** | تسوية مخزنية | تعديل وتصحيح رصيد الصنف لمطابقة الجرد الفعلي للمحل مع الرصيد المسجل في النظام لمعالجة التالف أو الفروقات. |

## 2. المصطلحات المالية والتكاليف والأرباح (Financial & Costing Terms)

| المصطلح بالإنجليزية | المصطلح بالعربية | الشرح والتعريف البرمجي والتشغيلي |
| :--- | :--- | :--- |
| **Cost Price** | سعر التكلفة | القيمة الحقيقية لشراء الصنف من المورد، وهي مفصولة تمامًا في قاعدة البيانات عن سعر البيع لحساب هامش الربح بدقة. |
| **Selling Price** | سعر البيع الافتراضي | السعر الأساسي المعروض لبيع الصنف للمستهلك النهائي، ويمكن تعديله أو منح خصم عليه أثناء إنشاء فاتورة البيع. |
| **Weighted Average Cost (WAC)** | متوسط التكلفة المرجح | معادلة محاسبية لحساب متوسط تكلفة الوحدة عند الشراء بأسعار مختلفة على دفعات متعددة: `(قيمة المخزون الحالي + قيمة الشحنة الجديدة) ÷ إجمالي الكمية`. |
| **Cost of Goods Sold (COGS)** | تكلفة البضاعة المباعة | إجمالي تكلفة الأصناف التي تم بيعها فعليًا خلال فاتورة معينة أو فترة زمنية محددة. |
| **Gross Profit** | إجمالي الربح | الفارق المالي المباشر المحقق: `صافي المبيعات (Net Sales) - تكلفة البضاعة المباعة (COGS)`. |
| **Profit Margin** | هامش الربح | النسبة المئوية التي توضح ربحية المبيعات: `(إجمالي الربح ÷ صافي المبيعات) × 100`. |
| **Subtotal** | الإجمالي الفرعي | مجموع قيم أسطر الفاتورة قبل احتساب أي خصومات على مستوى الفاتورة أو مصاريف إضافية. |
| **Discount** | الخصم | تخفيض مالي يُطبق إما كنسبة مئوية (%) أو كقيمة ثابتة، ويُتاح على مستويين: خصم على سطر الصنف وخصم على إجمالي الفاتورة. |
| **Net Total** | صافي الفاتورة النهائي | المبلغ الإجمالي النهائي المطلوب سداده بعد خصم كافة التخفيضات: `Subtotal - Discounts`. |

## 3. مصطلحات الفواتير والمدفوعات (Invoices & Payments Terms)

| المصطلح بالإنجليزية | المصطلح بالعربية | الشرح والتعريف البرمجي والتشغيلي |
| :--- | :--- | :--- |
| **Sales Invoice** | فاتورة بيع | المستند المالي والقانوني الصادر للعميل عند البيع، ويؤدي اعتماده إلى خصم فوري للمخزون وقيد مالي على العميل. |
| **Purchase Invoice** | فاتورة شراء | المستند الصادر من المورد عند توريد بضاعة للمحل، ويؤدي اعتماده إلى زيادة فورية في المخزون وتحديث متوسط التكلفة وحساب المورد. |
| **Cash Invoice** | فاتورة نقدية | فاتورة يتم سداد قيمتها بالكامل لحظة إنشائها، ويكون المبلغ المتبقي فيها صفرًا. |
| **Credit Invoice** | فاتورة آجلة | فاتورة يُسلّم فيها المنتج للعميل دون تحصيل فوري أو بتحصيل جزء فقط، ويُسجل باقي المبلغ كدين على حساب العميل. |
| **Partial Payment** | سداد جزئي | دفع جزء من قيمة الفاتورة أثناء الإنشاء أو لاحقًا، مع بقاء الفاتورة مفتوحة ومسجلة في قائمة المستحقات. |
| **Remaining Amount** | المبلغ المتبقي | القيمة المستحقة المتبقية على العميل لصالح المتجر: `صافي الفاتورة - إجمالي المدفوعات المسجلة عليها`. |
| **Payment Voucher / Receipt** | سند قبض / دفعة | حركة مالية مسجلة في جدول المدفوعات المستقل لسداد جزء أو كل الفاتورة، مرتبطة بالعميل والفاتورة والمستخدم المستلم. |
| **Sales Return** | مرتجع مبيعات | مستند مستقل يوثق إرجاع العميل لصنف أو أكثر من فاتورة سابقة، ويُعيد الكمية للمخزون ويخصم قيمتها من رصيد العميل أو يُرد نقدًا. |
| **Partial Return** | مرتجع جزئي | إرجاع جزء من كمية صنف أو صنف واحد من أصل عدة أصناف موجودة في الفاتورة دون الحاجة لإلغاء الفاتورة بالكامل. |
| **Cancel Invoice** | إلغاء الفاتورة | إبطال الفاتورة بالكامل وتغيير حالتها إلى Cancelled، مع عكس حركة المخزون وعكس القيد المالي للعميل مع الاحتفاظ بالسجل وعدم حذفه. |
| **Statement of Account** | كشف حساب | تقرير مالي يعرض تفاصيل كافة الحركات المالية والفواتير والمدفوعات والمرتجعات والرصيد التراكمي لعميل أو مورد معين. |

## 4. مصطلحات الهندسة البرمجية وقواعد البيانات (Architecture & DB Terms)

| المصطلح بالإنجليزية | المصطلح بالعربية | الشرح والتعريف البرمجي والتشغيلي |
| :--- | :--- | :--- |
| **DB Transaction** | المعاملة البرمجية لقاعدة البيانات | كتلة برمجية `DB::transaction()` تضمن تنفيذ سلسلة من التعديلات المعقدة معًا كوحدة واحدة؛ إذا فشلت أي خطوة يتم التراجع الكامل (Rollback). |
| **Row Locking (lockForUpdate)** | القفل السطري أثناء التحديث | آلية في SQL تقوم بحجز وحبس صف الصنف في قاعدة البيانات لمنع أي جلسة أخرى من قراءته أو بيعه في نفس اللحظة حتى اكتمال الـ Transaction. |
| **DECIMAL(12,3)** | دقة البيانات العشرية | نوع بيانات صارم في قاعدة البيانات مخصص للمبالغ المالية والكميات والأوزان (12 رقمًا إجماليًا منها 3 بعد الفاصلة) لمنع أخطاء التقريب الناتجة عن Float. |
| **Audit Log** | سجل التدقيق والرقابة | جدول مستقل يسجل الأحداث والعمليات الحساسة (إنشاء، تعديل، إلغاء، حذف، وصلاحيات) مع توثيق هوية المستخدم والقيم السابقة واللاحقة والتوقيت. |
| **Foreign Key** | المفتاح الأجنبي | قيد علائقي يضمن ربط الجداول ببعضها بإحكام (مثل ربط أسطر الفاتورة برقم الفاتورة الأصلي) ومنع وجود بيانات يتيمة أو غير متسقة. |
| **Unique Constraint** | قيد التفرد | قيد على مستوى قاعدة البيانات يمنع تكرار قيم معينة مثل كود الصنف (Item Code) أو رقم الفاتورة (Invoice Number) أو البريد الإلكتروني. |

## 5. مصطلحات الواجهة والأداء (Frontend & UI Terms)

| المصطلح بالإنجليزية | المصطلح بالعربية | الشرح والتعريف البرمجي والتشغيلي |
| :--- | :--- | :--- |
| **Livewire 4** | إطار العمل التفاعلي | مكتبة تسمح ببناء واجهات فائقة الديناميكية وتحديث أجزاء من الصفحة لحظيًا عبر استجابات خادم سريعة دون إعادة تحميل الصفحة (No Page Reload). |
| **Alpine.js** | مكتبة الجافاسكريبت الخفيفة | أداة مدمجة مع Livewire للتعامل مع التفاعلات الصغيرة جداً في المتصفح مثل فتح القوائم المنسدلة، الـ Modals، وتأثيرات الواجهة دون طلب من السيرفر. |
| **wire:navigate** | التنقل السلس بين الصفحات | خاصية في Livewire تُحول التنقل بين الروابط إلى SPA-like Navigation بتحميل محتوى الصفحة في الخلفية دون إعادة تحميل الأصول (Assets). |
| **RWD (Responsive Web Design)** | التصميم المتجاوب | توافق عناصر وتخطيط الشاشات تلقائيًا لتعمل بشكل مثالي على أجهزة الكمبيوتر، الأجهزة اللوحية (Tablets)، والهواتف الذكية. |
| **Mobile First** | أولوية الموبايل | منهجية تصميم تبدأ ببناء واجهات مريحة وقابلة للاستخدام السهل بيد واحدة على شاشات الهواتف ثم التوسع للشاشات الأكبر. |
| **PWA (Progressive Web App)** | تطبيق الويب التقدمي | تقنية تُمكّن تثبيت الموقع كتطبيق أصلي على الموبايل والكمبيوتر بوجود أيقونة مخصصة وService Worker وتشغيل في نافذة مستقلة. |
| **Thermal 80mm Print** | طباعة الإيصالات الحرارية | نمط طباعة مخصص لطابعات الفواتير الصغيرة السريعة بعرض 80 ملم وتنسيق مدمج بدون هوامش وبدون ألوان لتوفير الورق والسرعة. |
| **A4 Print** | طباعة المستندات القياسية | نمط طباعة فواتير رسمية وتقارير مالية وكشوف حسابات على ورق A4 القياسي بتنسيق أنيق وجداول متسعة وهوامش مضبوطة. |
