# المهارات والحزم البرمجية المطلوبة (Required Skills & Packages)

دليل شامل للمهارات التقنية، حزم Composer و NPM، وأدوات التطوير المطلوبة لتنفيذ وصيانة نظام إدارة الفواتير والمخزون، مع توضيح سبب اختيار كل أداة، والموديول المرتبط بها، والبدائل المقارنة.

## 2. تفاصيل متطلبات المهارات الفنية لفريق العمل (Skill Descriptions)

### 2.1 مهارات المعالجة الخلفية والأمان (Backend & Database Skills)
* **المعاملات والقفل السطري (Transactions & Row Locking):**
  * إتقان استخدام `DB::transaction()`، والتعامل مع الاستثناءات (Exceptions)، وضمان التراجع التام (Rollback).
  * فهم عميق لكيفية عمل `lockForUpdate()` في محرك InnoDB لمنع مشكلات الـ Race Conditions والبيع المزدوج لنفس الصنف.
* **الدقة المحاسبية والبيانات العشرية (Decimal Arithmetic):**
  * ضبط حقول الجداول على `DECIMAL(12,3)`.
  * إتقان دوال `bcmath` في PHP (`bcadd`, `bcsub`, `bcmul`, `bcdiv`, `bccomp`) لتجنب أخطاء التقريب الناتجة عن الـ Float.

### 2.2 مهارات الواجهات التفاعلية واللغة العربية (Frontend & RTL Skills)
* **تطوير Livewire 4 المتقدم:**
  * إتقان ربط النماذج الحية (`wire:model.live.debounce.300ms`).
  * التحكم في حالات التحميل (`wire:loading`, `wire:target`).
  * إدارة الأحداث والاتصال بين المكونات (`$this->dispatch()`, `#[On]`).
  * التنقل السلس بين الصفحات (`wire:navigate`).
* **التوافق التام مع اللغة العربية (RTL Mastery):**
  * بناء هيكل HTML متوافق مع `dir="rtl"`.
  * استخدام فئات Tailwind المنطقية (`ps-`, `pe-`, `ms-`, `me-`, `text-start`, `text-end`).
  * ضبط خطوط Cairo / Tajawal لضمان مقروئية الأرقام العربية والإنجليزية داخل الجداول.

### 2.3 مهارات الطباعة الحرارية والمستندات (Print Engineering Skills)
* **تنسيق ورق A4:** إعداد `@page { size: A4 portrait; margin: 12mm; }` وفصل الجداول الطويلة لتفادي قطع الأسطر (Page Breaks).
* **تنسيق الطابعات الحرارية 80mm:** إعداد `@page { size: 80mm auto; margin: 0; }`، وضبط عرض المحتوى ليكون مدمجًا بين 72mm إلى 80mm، وتوليد أكواد الـ QR والباركود الفورية.

### 2.4 مهارات تطبيقات الويب التقدمية (PWA & Offline Strategy)
* تجهيز ملف `manifest.json`، وتوفير الأيقونات بمقاسات 192x192 و 512x512، وتحديد نمط العرض `display: standalone`.
* كتابة Service Worker خفيف يقوم بعمل Cache لملفات الواجهة الثابتة مع توجيه طلبات البيع والمخزون الحساسة لتتطلب اتصالاً مباشرًا بالخادم حمايةً للبيانات.
