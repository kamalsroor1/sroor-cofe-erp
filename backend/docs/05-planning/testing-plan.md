## 🌐 3. خطة E2E Testing بالمتصفح — Python Playwright (التفاصيل الكاملة)

### 3.1 البيئة والمتطلبات (Prerequisites)

```bash
# 1. تشغيل سيرفر Laravel محلياً
php artisan serve --port=8000

# 2. تثبيت أدوات الاختبار
pip install playwright pytest pytest-asyncio
playwright install chromium

# 3. تشغيل الاختبارات
pytest tests_e2e/ -v --headed        # مع فتح المتصفح (مرئي — للمتابعة)
pytest tests_e2e/ -v                 # بدون متصفح (headless — أسرع)
```

### 3.2 هيكل ملفات E2E

```
tests_e2e/
├── conftest.py                          # إعدادات pytest + Playwright المشتركة
├── config.py                            # روابط + بيانات الدخول + ثوابت
├── helpers.py                           # دوال مساعدة (login, wait_for_livewire, etc.)
│
├── test_01_auth_and_navigation.py       # تسجيل الدخول + التنقل بين الصفحات
├── test_02_items_and_inventory.py       # إضافة أصناف + مخزون افتتاحي + بحث
├── test_03_customers_and_suppliers.py   # إضافة عملاء/موردين + أرصدة + كشف حساب
├── test_04_purchases_and_stock.py       # فاتورة شراء + توريد مخزون + WAC
├── test_05_pos_sales_and_invoices.py    # نقطة البيع: بيع كسري + نقدي + آجل + طباعة
├── test_06_stock_transfers.py           # تحويل بضاعة بين الفروع والعربات
├── test_07_shifts_and_journal.py        # فتح/إغلاق وردية + اليومية + Z-Report
├── test_08_expenses_and_returns.py      # تسجيل مصروفات + مرتجعات مبيعات/مشتريات
├── test_09_reports_and_exports.py       # تقارير الأرباح + تصدير CSV + مقارنة فروع
├── test_10_trash_and_permissions.py     # سلة المحذوفات + حظر الكاشير من الصفحات المقيدة
│
└── run_all_tests.py                     # مشغّل موحد يجمع PHPUnit + Playwright
```
