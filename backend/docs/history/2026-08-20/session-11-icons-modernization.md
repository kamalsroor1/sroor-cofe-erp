## 2. القرارات التقنية:

1. **الاعتماد على مكتبة `lucide-vue-next` (Tree-Shakeable):**
   * تحميل واستدعاء الأيقونات كـ Components خفيفة وسريعة دون أي تحميل زائد على الحزمة.
   * الأيقونات تدعم التحجيم التلقائي وتعتمد ألوان Tailwind CSS وحالات الوضع الفاتح والداكن والهوية الديناميكية `text-theme-primary`.
2. **تحسين حجم الشعار:**
   * رفع مساحة صندوق الشعار إلى 56px (`w-14 h-14`) لضمان وضوحه التام.
3. **دعم الشعار المزدوج للوضعين الفاتح والداكن (Dual Logo):**
   * إتاحة رفع شعارين منفصلين مع تبديل CSS فوري بصفر تأخير (`dark:hidden` / `hidden dark:block`).
4. **تكامل منتقي الألوان التقويمي (Interactive Color Calendar & Swatches):**
   * ربط كافة أزرار الإجراءات الأساسية بالهوية المحددة فوريًا.
