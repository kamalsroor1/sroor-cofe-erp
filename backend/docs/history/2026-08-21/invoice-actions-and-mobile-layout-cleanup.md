# سجل تعديل: حل تداخلات كروت الفواتير وبناء قائمة الإجراءات المرنة (Action Menu)
* **التاريخ والوقت:** 2026-08-21 02:40
* **الدور المفعل:** Frontend UI & UX Architect Agent
* **الهدف:** حل تداخلات العناصر والنصوص في كروت الفواتير (`Invoices/Index.vue`) وصفحة تفاصيل الفاتورة (`Invoices/Show.vue`)، وبناء مكون قائمة إجراءات مرن وقابل للتوسع المستقبلي (`Components/ActionMenu.vue`) يظهر كـ Bottom Action Sheet على الهواتف وDropdown Menu على أجهزة الكمبيوتر.

## 1. الملفات المعدلة:
* `[NEW]` `backend/resources/js/Components/ActionMenu.vue` - مكون قائمة إجراءات موحد ومنظم، يظهر على الموبايل كـ Bottom Action Sheet لمسي منبثق من الأسفل بأزرار كبيرة `min-h-[48px]` مع زر إغلاق صريح، وعلى الكمبيوتر كقائمة منسدلة أنيقة.
* `[MODIFIED]` `backend/resources/js/Pages/Invoices/Index.vue` - إعادة تنظيم بطاقات الموبايل بالكامل لمنع أي تداخل بين رقم الفاتورة، شارة الفرع، اسم وهاتف العميل، الإجماليات، واستبدال تكديس الأزرار بـ Quick View + Quick Print + قائمة إجراءات شاملة `•••`.
* `[MODIFIED]` `backend/resources/js/Pages/Invoices/Show.vue` - إعادة تصميم الترويسة العلوية وشريط الإجراءات، ليكون رقم الفاتورة والبيانات منظمة بشكل انسيابي بدون أي التفاف مشوه أو تكدس أزرار.

## 2. القرارات التقنية:
* اعتماد نمط Action Menu الذكي لاستيعاب أي إجراءات مستقبلية (مثل سند قبض، مرتجع مبيعات، مشاركة واتساب، تصدير ضريبي) دون ازدحام الواجهة أو كسر التصميم.
* التزام تام بنظام Touch Targets (أزرار وحقول >= 44px) وتأثيرات `active:scale-95`.
* دعم كامل للوضعين الفاتح والداكن والهوية البصرية الزمردية/الكهرمانية.
