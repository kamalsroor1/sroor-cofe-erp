# سجل تعديل: تطبيق أنيميشن السحب الأفقي العربي RTL Horizontal Swipe وتثبيت الهيكل
* **التاريخ والوقت:** 2026-08-21 20:47
* **الدور المفعل:** Frontend / UI Specialist
* **الهدف:** تفعيل نمط السحب الأفقي العربي المتناسق (RTL Horizontal Swipe) للتنقل بين الصفحات وتثبيت هيكل الـ Layout والـ Bottom Bar في App.vue لمنع أي وميض أو اختفاء أثناء التنقل.

## 1. الملفات المعدلة:
* `[MODIFIED]` `backend/resources/css/app.css` - إضافة كلاسات `.page-enter-from` و `.page-leave-to` لانزلاق الشاشات أفقياً من اليمين لليسار (`translateX(28px) -> 0 -> -20px`) بمرونة `cubic-bezier(0.16, 1, 0.3, 1)`.
* `[MODIFIED]` `backend/resources/js/App.vue` - تثبيت `SpaLayout` كـ Persistent App Shell.
* `[MODIFIED]` `backend/resources/js/views/*` - إزالة التكرار لوسم `SpaLayout` من كافة الـ Views لتخفيف الحجم وتسريع الرندر.

## 2. القرارات التقنية:
* **حركة السحب العربي الطبيعية:** الدخول يبدأ من اليمين بخطوة ناعمة `translateX(28px)` مع تلاشي تدريجي وتكبير طفيف `scale(0.99)`، بينما تغادر الصفحة السابقة نحو اليسار `translateX(-20px)` بضبابية خاطفة.
* **ثبات الـ Shell:** تم تثبيت شريط التنقل السفلي والعلوي والجانبي بشكل دائم، بحيث لا يعاد بناؤها إطلاقاً أثناء التنقل.

* [x] انخفاض حجم حزمة التطبيق الرئيسية من 337 KB إلى 215 KB.
* [x] اختبار التنقل والتأكد من انسيابية وثبات الـ Bottom Bar والـ Header.
