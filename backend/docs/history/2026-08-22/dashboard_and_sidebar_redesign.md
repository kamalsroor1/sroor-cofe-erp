# سجل تعديل: مطابقة واجهة لوحة التحكم (Dashboard) والشريط الجانبي 100% مع التصميم المرجعي

* **التاريخ والوقت:** 2026-08-22 20:00
* **الدور المفعل:** Frontend UI & Backend Architect
* **الهدف:** إعادة هيكلة وتصميم لوحة التحكم الرئيسية والشريط الجانبي لتتطابق بنسبة 100% مع الصورة المرجعية للنظام القديم.

## 1. الملفات المعدلة:
* `[MODIFIED]` `backend/resources/js/views/DashboardView.vue` - إعادة بناء وترتيب كروت المؤشرات الـ 4، جدول آخر الفواتير الصادرة (70%)، قائمة تنبيهات النواقص بالمخزن (30%)، وأزرار الترويسة العلوية السريعة.
* `[MODIFIED]` `backend/resources/js/Layouts/SpaLayout.vue` - إضافة زر "+ فاتورة بيع جديدة (F2)" البارز باللون العنبري في أعلى السايدبار، تنظيم المجموعات التصنيفية (المبيعات، الحسابات، المخزون، التقارير، الإدارة)، وإضافة الساعة والتاريخ الحي باللغة العربية في الهيدر.
* `[MODIFIED]` `backend/app/Actions/Dashboard/GetDashboardOverviewAction.php` - ضبط جلب آخر 8 فواتير مبيعات مع تواريخها وحالاتها ومبالغها المتبقية.
